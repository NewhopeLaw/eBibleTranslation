# Mark 3

¹ ဒီးဟဲက့ၤဝဲဆူတၢ်အုၣ်က့ၤခီၣ်က့ၤကီၢ်ပူၤလီၤ. ဒီးပှၤကညီလၢအစုကိၢ်တၢ်ဂီၤတဂၤန့ၣ်, အိၣ်ဒီးအီၤလီၤ. ² ဒီးမ့ၢ်အမၤဘျါက့ၤအီၤလၢမုၢ်ဆ့ၣ်ထီၣ်တနံၤန့ၣ်ဒီး, ပှၤကိာ်ထီၣ်အီၤ, ဒ်သိးအကမၤသံအီၤလီၤ. ³ ဒီးစံးဝဲဒၣ်, ပှၤလၢအစုကိၢ်တၢ်ဂီၤန့ၣ်, ဟဲဆူပူၤတက့ၢ်. ⁴ ဒီးစံးဝဲဒၣ်, လၢမုၢ်ဆ့ၣ်ထီၣ်တနံၤန့ၣ်, ပှၤမၤဂ့ၤတၢ်, ဒီးမၤကမၣ်တၢ်, ဒီးပာ်ခူသူၣ်တၢ်, ဒီးမၤသံတၢ်န့ၣ်, ကဲထီၣ်တၢ်ဂ့ၤ, ဒီးမၤကမၣ်တၢ်, ဒီးပာ်ခူသူၣ်တၢ်, ဒီးမၤသံတၢ်န့ၣ်, တမ့ၢ်ဘၣ်လဲၣ်. ဒီးအသးကိၢ်ဘၣ်ဂီၤလီၤ. ⁵ ဒီးကွၢ်က့ၤအီၤဝးတရံးဝဲ, ဒီးအသးကိၢ်တၢ်ဂီၤ, ဒီးစံးဝဲဒၣ်, ဒုးဟဲထီၣ်နစုတက့ၢ်. ဒီးဒုးဟဲထီၣ်အီၤ, ဒီးအစုဟဲက့ၤကဒါက့ၤလီၤ. ⁶ ဒီးပှၤဖၤရံၤရၤဖိဟဲက့ၤဝဲ, ဒီးမၤသးဒ်ပှၤဃၤရၤဖိအသိး, ဒ်သိးအကမၤသံအီၤလီၤ. ⁷ ဒီးစံးဝဲဒၣ်, စီၤယၤကိာ်ဟဲဝဲ, ဒီးတပီၣ်ထီၣ်အီၤဆူပီၣ်လဲၣ်ပူၤ, ဒီးပှၤအါဂၤလၢကံၣ်စရ့လးန့ၣ်ဟဲဝဲဒီးအီၤလီၤ. ⁸ ဒီးပှၤယူဒၤဖိ, ဒီးယရူၤၡယၤဖိ, ဒီးဧၤဒၤဖိ, ဒီးယရူၤၡယၤအပူၤ, ဒီးပှၤတၤရၤဖိ, ဒီးၡၤဒၤဖိ, ပှၤအါဂၤ, ဒီးနၢၤတၢ်လၢအမၤန့ၣ်, ဒီးဟဲထီၣ်ဆူအပူၤလီၤ. ⁹ ဒီးစံးဝဲဒၣ်, ဒ်သိးပှၤကလုာ်တဖၣ်သုတမၤသံအီၤအဃိဒီး, မၤသးဒ်န့ၣ်ဒီးစံးဝဲဒၣ်, မ်အပျဲၢ်အဘီၣ်ပာ်ကဘီတဘီလၢအဂီၢ်တက့ၢ်. ¹⁰ ဘၣ်ဆၣ်ဒီးမၤဘျါက့ၤပှၤအါဂၤ, ဒ်သိးပှၤအိၣ်ဒီးတၢ်ဒုၣ်ဒွဲၣ်တဖၣ်ကထိၣ်ကဒါက့ၤအီၤ, ဒ်သိးအကထိၣ်အီၤလီၤ. ¹¹ ဒီးတၢ်သးကလီကလီတဖၣ်, ဒီးတုၤအထံၣ်ဘၣ်အီၤဒီး, လီၤဃၢၤလၢအပူၤ, ဒီးသံဝဲ, ဒီးစံးဝဲဒၣ်, နမ့ၢ်ယွၤဖိခွါလီၤ. ¹² ဒီးစံးဝဲဒၣ်, မ်အသုတသ့ၣ်ညါအီၤဘၣ်. ¹³ ဒီးဟဲဝဲဆူကစၢၢ်ကလိ, ဒီးစံးဝဲဒၣ်, ပှၤလၢအဘၣ်အီၤတဖၣ်, ဒုးဟဲက့ၤအီၤ, ဒီးဟဲဝဲဆူအီၤလီၤ. ¹⁴ ဒီးပာ်ပှၤတဆံခံဂၤ, ဒ်သိးအကကဲထီၣ်ဒီးအီၤ, ဒီးဒ်သိးအကဒုးဟဲစိာ်အီၤဆူတၢ်အုၣ်က့ၤခီၣ်က့ၤတၢ်အဂီၢ်, ¹⁵ ဒီးဒ်သိးအကပာ်ကွံာ်တၢ်လီတၢ်လီန့ၣ်ဒီး, မ်အမၤလိာ်အီၤတက့ၢ်. ¹⁶ ဒီးပာ်ပှၤတဆံခံဂၤ, ဒီးစံးဝဲဒၣ်, စီၤၡံယၤ, စံးဝဲဒၣ်, စီၤပ့းတရူးလီၤ. ¹⁷ ဒီးစီၤစဘၤဧၤစီၤယၤကိာ်, ဒီးစီၤယၤကိာ်အပၢ်စီၤယၤကိာ်, ဒီးစံးဝဲဒၣ်, စံးဝဲဒၣ်, ပှၤဘၤဧၤနာ်ကၤဖိ, မ့ၢ်အစံး, ပှၤမ့ၣ်အူဖိလီၤ. ¹⁸ ဒီးစီၤအၤနရိၤ, ဒီးစီၤဖၤရိၤ, ဒီးစီၤဘၤရၤသလၤ, ဒီးစီၤမးသဲ, ဒီးစီၤတၤမါ, ဒီးစီၤအၤလၤဖိစီၤယၤကိာ်, ဒီးစီၤတၤဒၤ, ဒီးစီၤၡံယၤ, ပှၤကၤနၣ်ဖိ, ¹⁹ ဒီးစီၤယူဒၤ, စီၤအၤစကၤရၤယၤ, စီၤအၤစကၤရၤယၤန့ၣ်, မ့ၢ်ပှၤမၤသံအီၤလီၤ. ²⁰ ဒီးဟဲဝဲဆူဟံၣ်ပူၤ, ဒီးပှၤအါဂၤအိၣ်ဖှိၣ်ရိဖှိၣ်လီၤ. ဒ်သိးအကအီၣ်တၢ်ဘၣ်န့ၣ်, တမၤဘၣ်အီၤဘၣ်. ²¹ ဒီးတုၤအဟံၣ်ဖိနၢၤတၢ်န့ၣ်ဒီး, ဟဲက့ၤကဒါက့ၤဒ်သိးအကပာ်ထီၣ်ထီအီၤလီၤ. ဘၣ်ဆၣ်ဒီးစံးဝဲဒၣ်, အသးကိာ်လီၤ. ²² ဒီးပှၤအုၣ်က့ၤခီၣ်က့ၤတၢ်တဖၣ်ဟဲဝဲလၢယရူၤၡယၤ, ဒီးစံးဝဲဒၣ်, အိၣ်ဒီးဘၤစၤဘံၣ်လီၤ. ဒီးဒုးဟဲစိာ်တၢ်ကမၣ်လၢတၢ်လီတၢ်လီအခိၣ်လီၤ. ²³ ဒီးဟဲစိာ်အီၤ, ဒီးစံးဝဲဒၣ်လၢတၢ်အုၣ်က့ၤခီၣ်က့ၤအပူၤ, ဒီးစံးဝဲဒၣ်, စီၤၡၤၡၤမၤသံကွံာ်စီၤၡၤၡၤဒ်လဲၣ်. ²⁴ စီၤပၤတဂၤန့ၣ်, မ့ၢ်ကွဲၤဝဲဒီးအီၤဒီး, စီၤပၤအံၤ, တအိၣ်ဘၣ်လီၤ. ²⁵ ဒီးဟံၣ်တဂၤန့ၣ်, မၤသးဒ်န့ၣ်ဒီး, မၤသးဒ်န့ၣ်ဒီး, ဟံၣ်အံၤ, မၤသးဒ်န့ၣ်ဒီး, မၤသးဒ်န့ၣ်ဒီး, ဟံၣ်အံၤ, မ့ၢ်အကွဲလီၤ. ²⁶ ဒီးစီၤစီလူးမ့ၢ်ဟဲက့ၤဆူအလိၤ, ဒီးကွဲၤဝဲဒီး, တအိၣ်ဘၣ်လီၤ. ဘၣ်ဆၣ်ဒီး, အကတၢၢ်ဟဲဝဲလီၤ. ²⁷ ဘၣ်ဆၣ်ဒီး, မ်အမတၤဆိၣ်ထီၣ်ပှၤလုၢ်တၢ်ဒိၣ်န့ၣ်ဒီး, မ်အမတၤဟဲက့ၤဆူပှၤလုၢ်တၢ်ဒိၣ်အဟံၣ်ပူၤ, ဒီးလုးကွံာ်အဟံၣ်အလိၤနီတဂၤဘၣ်. ဒီးဖဲန့ၣ်ဒီး, ကလုးကွံာ်အဟံၣ်လီၤ. ²⁸ ယစံးဘၣ်တဲဘၣ်သုတီတီလိၤလိၤ, ပှၤကညီဖိခွါန့ၣ်, တၢ်သူၣ်ဖှံသးညီကကဲထီၣ်လၢတၢ်ကမၣ်ခဲလၢာ်, ဒီးလၢတၢ်အုၣ်က့ၤခီၣ်က့ၤတၢ်ခဲလၢာ်လီၤ. ²⁹ မ့ၢ်မတၤမၤကမၣ်တၢ်လၢအသးစီဆှံန့ၣ်, မ်အသုတမၤပၢၤအီၤဘၣ်. ဘၣ်ဆၣ်ဒီး, ကဲထီၣ်တၢ်ကမၣ်အထူအထူလီၤ. ³⁰ ဘၣ်ဆၣ်ဒီးအဝဲသ့ၣ်စံးဝဲဒၣ်, မ့ၢ်အအိၣ်ဒီးတၢ်သးကလီကလီလီၤ. ³¹ ဒီးအပၢ်ဒီးအပၢ်တဖၣ်ဟဲဝဲ, ဒီးအိၣ်ဖှိၣ်ရိဖှိၣ်လၢပူၤ, ဒီးမၢလီၤပှၤဟဲစိာ်အီၤဆူအပူၤလီၤ. ³² ဒီးပှၤအါဂၤနၢၤဝဲဝးတရံးအီၤ, ဒီးစံးဝဲဒၣ်, ကွၢ်ကွၢ်, နပၢ်, ဒီးနပၢ်တဖၣ်, ဃ့နသးလၢပူၤလီၤ. ³³ ဒီးစံးဆၢအီၤ, ဒီးစံးဝဲဒၣ်, ယပၢ်, ဒီးယဖိခွါန့ၣ်, မ့ၢ်မတၤတဂၤလဲၣ်. ³⁴ ဒီးကွၢ်ဝဲ, ဒီးစံးဝဲဒၣ်, မၤသးဒ်န့ၣ်ဒီး, ပှၤအိၣ်ဝးတရံးအီၤတဖၣ်, ဒီးစံးဝဲဒၣ်, မၤသးဒ်န့ၣ်ဒီး, မၤသးဒ်န့ၣ်ဒီး, ယပၢ်, ဒီးယဖိခွါလီၤ. ³⁵ မ့ၢ်မတၤမၤယွၤအသးန့ၣ်, မ့ၢ်ယဖိခွါ, ဒီးယဖိခွါမုၣ်, ဒီးယပၢ်လီၤ.
