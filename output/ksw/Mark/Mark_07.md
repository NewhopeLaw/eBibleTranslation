# Mark 7

¹ ပှၤဖၤရံၤရၤဖိ, ဒီးပှၤအုၣ်က့ၤခီၣ်က့ၤတၢ်တဖၣ်, ဟဲဆူအီၤလၢယရူၤၡယၤ, ² ဒီးကွၢ်ကွၢ်, အပျဲၢ်အဘီၣ်အါဂၤ, အီၣ်တၢ်လၢအစုတဆ့ၣ်နီၤဘၣ်, မ့ၢ်အစုတတီတလိၤလီၤ. ³ ဘၣ်ဆၣ်ဒီးပှၤဖၤရူၤၡၢ်တဖၣ်, ဒီးပှၤယူဒၤဖိခဲလၢာ်န့ၣ်, ပာ်ထီၣ်ထီပှၤပှၢ်မုၢ်ကိၢ်တၢ်ဂီၤဒီး, မတၤဆ့ဘၣ်အစုဒီး, တအီၣ်ဘၣ်တၢ်ဘၣ်. ⁴ ဒီးတုၤအဟဲက့ၤကဒါက့ၤလၢစၢၢ်ကလိဒီး, မ်အသုတမၤကမၣ်ဘၣ်အီၤဒီး, တအီၣ်ဘၣ်တၢ်ဘၣ်. ဒီးတၢ်မၤအသးလၢအပာ်ထီၣ်ထီတၢ်အါဂၤလီၤ. တၢ်ဆ့ထးခိၣ်, ဒီးထးခီ, ဒီးသိတဝီလီၤ. ⁵ ဒီးပှၤဖၤရိၤဖိ, ဒီးပှၤသ့ၣ်ညါတၢ်တဖၣ်စံးဝဲဒၣ်, နဝံတဖၣ်တလဲၤဘၣ်ဒ်ပှၤပှၢ်မုၢ်ကိာ်အတၢ်မၤအသးအသိးဘၣ်, ဒီးအီၣ်တၢ်ဒီးစုတစုဘၣ်န့ၣ်, မ့ၢ်အဘၣ်မနုၤအဃိလဲၣ်. ⁶ ဒီးစံးဝဲဒၣ်, စီၤယၡါယၤစံးဝဲဒၣ်လၢဝံအသံလၢသုဂီၢ်, ပှၤမၤကမၣ်တၢ်တဂၤဧၢ, မ့ၢ်တၢ်တီလီၤ. ဒ်တၢ်စံးဝဲဒၣ်အသိးန့ၣ်, ပှၤအံၤဂုၤယၤလၢအပျုၤ, ဘၣ်ဆၣ်ဒီးအသးနးဘၣ်ယၤလီၤ. ⁷ မၤသးဒ်န့ၣ်ဒီး, မၤသးဒ်န့ၣ်ဒီး, ပှၤမၤကမၣ်ယၤန့ၣ်, မ့ၢ်တၢ်တတီတလိၤလီၤ. ⁸ ဒီးသုပာ်လီၤကွံာ်ယွၤတၢ်စံးပာ်, ဒ်သိးသုကထိၣ်ထီၣ်ပှၤတၢ်အုၣ်က့ၤခီၣ်က့ၤလီၤ. ⁹ ဒီးစံးဝဲဒၣ်, သုမၤတတီတလိၤဘၣ်ယွၤအကလုၢ်အကထါလၢသုတၢ်အုၣ်က့ၤခီၣ်က့ၤအဃိလီၤ. ¹⁰ ဘၣ်ဆၣ်ဒီးစီၤပၤစံးဝဲဒၣ်, ဂုၤနပၢ်ဒီးနပၢ်တက့ၢ်. ဒီး, ပှၤအုၣ်က့ၤခီၣ်က့ၤအပၢ်ဒီးအပၢ်န့ၣ်, မ်အသံလီၤ. ¹¹ ဘၣ်ဆၣ်ဒီးသုစံး, ပှၤမ့ၢ်စံးဝဲလၢအပၢ်မ့ၢ်ဂ့ၤ, အပၢ်တဂၤမ့ၢ်ဂ့ၤ, တၢ်လၢအဘၣ်နဟ့ၣ်လၢယၤန့ၣ်, မ့ၢ်ကံၣ်ဘၣ်လီၤ. ¹² ဒီးသုတပာ်ဘၣ်အီၤဒ်သိးအကမၤအပၢ်မ့ၢ်ဂ့ၤ, အပၢ်မ့ၢ်ဂ့ၤဘၣ်. ¹³ ဒီးသုမၤတတီတလိၤဘၣ်ယွၤအကလုၢ်အကထါလၢသုတၢ်အုၣ်က့ၤခီၣ်က့ၤလၢသုမၤလီၤ. ဒီးသုမၤတၢ်အါဂၤဒ်တၢ်အံၤအသိးလီၤ. ¹⁴ ဒီးဟဲစိာ်ပှၤကလုာ်တဖၣ်ဆူအီၤ, ဒီးစံးဝဲဒၣ်, မၤသးဒ်န့ၣ်ဒီး, ကိၢ်တၢ်ဂီၤလၢယၤတက့ၢ်. ဒီးသ့ၣ်ညါတၢ်တက့ၢ်. ¹⁵ တၢ်ဟဲက့ၤဆူပှၤပူၤလၢဟီၣ်ခိၣ်ချၢန့ၣ်, တမ့ၢ်ဘၣ်အမၤတကဲဘၣ်အီၤဘၣ်. ပှၤလၢအဟဲက့ၤဆူပှၤပူၤန့ၣ်, မ့ၢ်အမၤတကဲဘၣ်အီၤလီၤ. ¹⁷ ဒီးတုၤအဟဲဝဲဆူဟံၣ်ပူၤဒီး, ပာ်ကွံာ်ပှၤကလုာ်တဖၣ်ဒီး, အပျဲၢ်အဘီၣ်စံးဝဲဒၣ်, တၢ်အုၣ်က့ၤခီၣ်က့ၤန့ၣ်, မ့ၢ်တၢ်ဒ်လဲၣ်ဒ်လဲၣ်န့ၣ်, ¹⁸ ဒီးစံးဝဲဒၣ်, သုသးကိၢ်တၢ်ဂီၤန့ၣ်, သုသးကိၢ်တၢ်ဂီၤဘၣ်ဧါ. မၤသးဒ်န့ၣ်ဒီး, တၢ်ခဲလၢာ်လၢအဟဲဆူပှၤပူၤလၢဟီၣ်ခိၣ်ချၢန့ၣ်, သုတသ့ၣ်ညါဘၣ်, ဒီးသုတမၤကလီကလီဘၣ်အီၤဘၣ်. ¹⁹ မၤသးဒ်န့ၣ်ဒီး, တဟဲဘၣ်ဆူသးပူၤဘၣ်. မၤသးဒ်န့ၣ်ဒီး, တဟဲဘၣ်ဆူထးခိၣ်ပူၤဘၣ်. ဒီးဟဲဝဲဆူထံပူၤလီၤ. (ဒီးစံးဝဲဒၣ်, တၢ်မၤသနၢၢ်တၢ်ခဲလၢာ်လီၤ. ) ²⁰ ဒီးစံးဝဲဒၣ်, တၢ်လၢအဟဲလီၤလၢပှၤအပူၤန့ၣ်, မ့ၢ်အမၤတမူတမူအီၤလီၤ. ²¹ ယွၤစံးဝဲဒၣ်, လၢပှၤအသးကံၢ်ပူၤန့ၣ်, တၢ်ကူၣ်တၢ်ဆး, တၢ်လီတၢ်လီ, တၢ်လုးတၢ်လီ, တၢ်သံတၢ်လီန့ၣ်, ဟဲဝဲလီၤ. ²² တၢ်လုးတၢ်လိၤ, တၢ်ပျံၤတၢ်ဖုး, တၢ်ညိတၢ်ညိ, တၢ်လီတၢ်လီ, တၢ်သးကိၢ်တၢ်ဂီၤ, တၢ်ဃ့ကညးတၢ်, တၢ်ဃူတၢ်ညၣ်, တၢ်ထးခိၣ်တၢ်, တၢ်သူၣ်ဖှံသးညီ, ²³ မၤသးဒ်န့ၣ်ဒီး, တၢ်ကမၣ်တဖၣ်ခဲလၢာ်န့ၣ်, ဟဲဝဲလၢဟီၣ်ခိၣ်ချၢ, ဒီးမၤတကဲဘၣ်ပှၤလီၤ. ²⁴ ဒီးလဲၤဝဲဆူညါ, ဒီးဟဲဝဲဆူစူၤရံအကီၢ်ပူၤ, ဒီးဟဲဝဲဆူဟံၣ်ပူၤ, ဒီးတသ့ၣ်ညါဘၣ်ပှၤနီတဂၤဘၣ်. ဘၣ်ဆၣ်ဒီး, ပာ်ခူသူၣ်ဘၣ်အီၤဘၣ်. ²⁵ ဒီးပှၤဖိခွါတဂၤ, ဒီးစီၤဧၤမါန့ၣ်, အိၣ်ဒီးအပၢ်အသးကလီကလီ, ဒီးနၢၤတၢ်ဆူအီၤ, ဒီးဟဲဝဲ, ဒီးကျီဝဲလၢအလိၤတပူၤဃီလီၤ. ²⁶ ဒီးပှၤဖိခွါအံၤ, ပှၤဂံၣ်စရ့လးဖိ, ပှၤစၤရၤဖၤနါဖိ, ဒီးစံးဝဲဒၣ်, မ်အဒုးဟဲစိာ်တၢ်လီတၢ်လီလၢအဖိခွါလီၤ. ²⁷ ဒီးစံးဝဲဒၣ်, ပာ်ပှၤဖိခွါတဖၣ်ကိၢ်တၢ်ဂီၤတက့ၢ်. မ့ၢ်မတၤပာ်ဖိခွါတဖၣ်အကိၢ်တၢ်ဂီၤ, ဒီးပာ်ကွံာ်အီၤဆူသိတဖၣ်အစုပူၤန့ၣ်, တမ့ၢ်ဘၣ်ဘၣ်. ²⁸ ဒီးအဝဲသ့ၣ်စံးဝဲဒၣ်, ယွၤဧၢ, ကစၢၢ်ကလိလၢစၢၢ်ကလိအပူၤန့ၣ်, အီပှၤဖိခွါအခိၣ်သလုးလီၤ. ²⁹ ဒီးစံးဝဲဒၣ်, မ့ၢ်အစံးတၢ်အံၤအဃိဒီး, လဲၤလီၤ. ပှၤဒုၣ်ဒွဲၣ်ဟဲက့ၤလၢနဖိခွါလီၤ. ³⁰ ဒီးဟဲဝဲဆူအဟံၣ်ပူၤ, ဒီးကွၢ်ကွၢ်, ပှၤဖိၣ်ဖိၣ်အိၣ်သယိာ်လၢလီၢ်မံပူၤ, ဒီးတၢ်ဒုၣ်ဒွဲၣ်ဟဲက့ၤဝဲလီၤ. ³¹ ဒီးဟဲက့ၤကဒါက့ၤကဒါက့ၤလၢၡၤရံအကီၢ်ပူၤ, ဒီးဟဲဝဲဆူစူၤဒၣ်, ဒီးဟဲဝဲဆူပီၣ်လဲၣ်ကံၣ်စရ့လး, လၢဒကၤပံၣ်အကီၢ်ပူၤလီၤ. ³² ဒီးဟဲစိာ်ဝဲဆူအပူၤပှၤကိၢ်တၢ်ဂီၤ, ဒီးပှၤသံတၢ်တဂၤ, ဒီးစံးဝဲဒၣ်, ပာ်အစုလၢအပူၤတက့ၢ်. ³³ ဒီးဟဲစိာ်အီၤ, ဒီးပာ်အစုပူၤလၢပှၤကလုာ်တဖၣ်အပူၤ, ဒီးဟ့ၣ်လီၤအစုလၢအထံပူၤ, ဒီးထးထီၣ်အပျၢ်, ဒီးထိၣ်ကွံာ်အပျၢၤလီၤ. ³⁴ ဒီးကွၢ်ဝဲဆူဟီၣ်ခိၣ်, ဒီးသံဝဲ, ဒီးစံးဝဲဒၣ်, ဧ့ဖၤသၤ, (မ့ၢ်တၢ်စံးဝဲဒၣ်, ဒုးဟဲထီၣ်နၤတက့ၢ်. ) ³⁵ ဒီးအထံလီၤဃၣ်ဝဲ, ဒီးအပျုၤလီၤဃၣ်ဝဲ, ဒီးစံးဘၣ်တဲဘၣ်တၢ်တတီတလိၤလီၤ. ³⁶ ဒီးစံးဝဲဒၣ်, မ်အသုတစံးဘၣ်တဲဘၣ်ပှၤနီတဂၤဘၣ်. ဘၣ်ဆၣ်ဒီးစံးဝဲဒၣ်အါအါကလဲာ်ဒီး, ပှၤစံးဝဲဒၣ်အါအါကလဲာ်လီၤ. ³⁷ ဒီးအဝဲသ့ၣ်သးကိၢ်သးဂီၤအါဂၤ, ဒီးစံးဝဲဒၣ်, မၤကမၣ်တၢ်ခဲလၢာ်လီၤ. မ့ၢ်အပာ်ပှၤနးဖိနးတၢ်, ဒီးပှၤနးဖိနးတၢ်န့ၣ်စံးတၢ်လီၤ.
