# 2 Chronicles 8

¹ ဒီးစီၤစီလူးမၤယွၤအလီၢ်, ဒီးစီၤစီလူးအဟံၣ်ခံဆံအနံၣ်န့ၣ်, ² ဒီးစီၤဃူရၤဟ့ၣ်စီၤၡၤမ့ၤလၢကီၢ်တဖၣ်, ဒီးစီၤၡၤမ့ၤမၤလိာ်အီၤ, ဒီးပာ်အံၣ်စရ့လးလၢအပူၤလီၤ. ³ ဒီးစီၤစီလူးဟဲဝဲဆူဃမါးၡဘၤ, ဒီးမၤဟးဂီၤအီၤလီၤ. ⁴ ဒီးပာ်ထီၣ်ထီတၤဒၤမံၣ်လၢကီၢ်ကိာ်ပူၤ, ဒီးဟံၣ်ပူၤကီၢ်တဖၣ်ခဲလၢာ်လၢအပာ်ထီၣ်ထီလၢဃမါတၤပူၤလီၤ. ⁵ ဒီးမၤဘ့ၤသဃၤရၣ်အလိၤ, ဒီးဘၤသဃၤရၣ်အလိၤ, စီၤပၤအကီၢ်တဖၣ်, အခိၣ်သလုး, ဒီးပဲတရီ, ဒီးဃၣ်ဒွဲၣ်လီၤ. ⁶ ဒီးပာ်လီၤဘဧၤလၤ, ဒီးဟီၣ်ခိၣ်အကီၢ်တဖၣ်ခဲလၢာ်လၢစီၤၡလိၤၡံအစုပူၤ, ဒီးကီၢ်တဖၣ်လၢကဘီတဖၣ်အဂီၢ်, ဒီးလၢကဘီဖိအဂီၢ်, ဒီးဟီၣ်ခိၣ်အကီၢ်တဖၣ်ခဲလၢာ်လၢစီၤၡလိၤၡံမၤလိာ်အီၤလၢယရူၤၡၣ်အပူၤ, ဒီးလၢလဘၤနၣ်အပူၤ, ဒီးလၢဟီၣ်ခိၣ်အကီၢ်ခဲလၢာ်အပူၤလၢအစုပူၤလီၤ. ⁷ ဒီးပှၤကညီခဲလၢာ်လၢပှၤဃၢၤဖိ, ဒီးပှၤဧၤမ့ၤဖိ, ဒီးပှၤဖၤရၤၡးဖိ, ဒီးပှၤဃံဖိ, ဒီးပှၤယဘၤဖိလၢအတကဲထီၣ်ဘၣ်ပှၤအံၣ်စရ့လးဖိန့ၣ်, ⁸ ဒီးပှၤအံၣ်စရ့လးဖိတမၤသံဘၣ်အီၤဘၣ်, ဒီးပှၤအံၣ်စရ့လးဖိတမၤသံဘၣ်အီၤဘၣ်, ဒီးပှၤအံၣ်စရ့လးဖိအပၢ်တဖၣ်လၢအအိၣ်ဖှိၣ်ရိဖှိၣ်လၢဟီၣ်ခိၣ်ချၢန့ၣ်စီၤၡလိၤၡံမၤဘၣ်အီၤ, ဒီးအိၣ်ဖှိၣ်ရိဖှိၣ်လၢအပူၤလၢမုၢ်မဆါတနံၤအံၤလီၤ. ⁹ ဒီးပှၤအံၣ်စရ့လးဖိန့ၣ်စီၤစီလူးတမၤဘၣ်အီၤဒ်သိးအကမၤတၢ်နီတဂၤဘၣ်. ဘၣ်ဆၣ်ဒီးအဝဲသ့ၣ်မ့ၢ်ပှၤသုးဖိ, ဒီးစီၤပၤအခိၣ်တဖၣ်, ဒီးကဘီတဖၣ်အခိၣ်, ဒီးကစၢၢ်ကလိအခိၣ်လီၤ. ¹⁰ မၤသးဒ်န့ၣ်ဒီးပှၤသုးမုၢ်အခိၣ်လၢစီၤပၤစီၤၡလိၤမိၤအစုပူၤန့ၣ်မ့ၢ်ပှၤလုၢ်တၢ်အဒိၣ်လၢဟီၣ်ခိၣ်ချၢ, ပှၤခံကယၤလွံၢ်ကယၤလီၤ. ¹¹ ဒီးစီၤစီလူးဟဲစိာ်ဖၤရိၤဖိခွါလၢစီၤဒၤဝံးအကီၢ်ပူၤဆူဟံၣ်လၢအမၤအီၤအပူၤလီၤ. ဘၣ်ဆၣ်ဒီးစံးဝဲဒၣ်, အံၣ်စရ့လးအစီၤပၤစီၤဒ့ၤဝံအကီၢ်အပူၤ, စီၤပၤဖိခွါတအိၣ်ဘၣ်လီၤ. ဒ်သိးယွၤအထးခိၣ်ဟဲက့ၤဆူအပူၤန့ၣ်မ့ၢ်တၢ်စီဆှံလီၤ. ¹² ဒီးမုၢ်တနံၤန့ၣ်စီၤၡလိၤၡံပာ်တၢ်လုၢ်မ့ၣ်အူလၢယွၤအဂီၢ်လၢတၢ်လုၢ်လီၢ်အပူၤလၢအပာ်ထီၣ်ထီအီၤလၢဟီၣ်ခိၣ်အလိၤအပူၤလီၤ. ¹³ ဒီးပာ်ထီၣ်ထီတၢ်အုၣ်က့ၤခီၣ်က့ၤလၢမုၢ်မဆါတနံၤအံၤ, ဒ်စီၤၡဘၤစံးဝဲဒၣ်အသိးန့ၣ်, လၢမုၢ်ဆ့ၣ်နီၤ, ဒီးလၢမုၢ်လၤဒိၣ်, ဒီးလၢအလုၢ်တၢ်အဒိၣ်တဖၣ်, သၢနံၤလၢနံၣ်အံၤ, လၢကိၣ်တကိၢ်ဘၣ်အလိၤအလိၤ, ဒီးလၢမုၢ်နွံနံၣ်အကျိၤအကျဲအပူၤ, ဒီးပီၣ်တဖၣ်အလိၤလီၤ. ¹⁴ ဒီးပာ်ပှၤလုၢ်တၢ်အဒိၣ်အကလုာ်တဖၣ်ဒ်အပၢ်စီၤဒၤဝံးမၤလိာ်အီၤအသိးန့ၣ်, ဒီးပှၤလ့ၤဝံဖိဒ်တၢ်အုၣ်က့ၤခီၣ်က့ၤအီၤအသိး, ဒ်သိးအကမၤတၢ်, ဒီးမၤသံတၢ်လၢပှၤအုၣ်က့ၤခီၣ်က့ၤတၢ်အပူၤ, တဂၤဒီးတဂၤဒ်မုၢ်တနံၤအသိးန့ၣ်, ဒီးပှၤထိၣ်ပဲတရီတဖၣ်ဒ်အကလုာ်တဖၣ်အသိးန့ၣ်, ဒ်ယွၤအပၢ်စီၤဒၤဝံးမၤလိာ်အီၤအသိးန့ၣ်လီၤ. ¹⁵ ဒီးစီၤစီလူးတဟဲစိာ်ဘၣ်လၢတၢ်အုၣ်က့ၤခီၣ်က့ၤပှၤလုၢ်တၢ်အဒိၣ်, ဒီးပှၤလ့ၤဝံဖိ, လၢတၢ်ခဲလၢာ်အပူၤ, ဒီးလၢတၢ်လုၢ်တၢ်ဒိၣ်အပူၤဘၣ်. ¹⁶ ဒီးစီၤၡၤမ့လးအတၢ်ခဲလၢာ်န့ၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢမုၢ်တနံၤလၢအမၤထီၣ်ထီအီၤ, ဒီးမုၢ်တနံၤလၢအမၤထီၣ်ထီအီၤလီၤ. ဒီးစီၤၡၤမ့လးအဟံၣ်န့ၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လီၤ. ¹⁷ ဒီးစီၤစီလူးဟဲဆူဧ့ၡၤဃဘၤ, ဒီးဧၤလၤလၢပီၣ်လဲၣ်ဃၣ်အခိၣ်လၢကီၢ်အၤဒၤပူၤလီၤ. ¹⁸ ဒီးစီၤဃူရၤမၢလီၤကဘီတဖၣ်လၢအပှၤသ့ၣ်ညါပီၣ်လဲၣ်တဖၣ်အစုပူၤ, ဒီးဟဲဝဲဒီးစီၤစီလူးအပှၤတဖၣ်ဆူအ့ဖၤရိး, ဒီးဟဲစိာ်ထူလွံၢ်ကယၤ, ဒီးဆံဆံ, ဒီးဟဲစိာ်အီၤဆူစီၤစီလူးလီၤ.
