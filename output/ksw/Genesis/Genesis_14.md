# Genesis 14

¹ လၢၡၤနၣ်အစီၤပၤအၤမၤရဖၤ, ဒီးဧၤလၡၣ်အစီၤပၤအၤရၤဃး, ဒီးဧၤလၣ်အစီၤပၤကဒၤရလဧၣ်, ဒီးဂံအစီၤပၤတၤဒၤ, ² ဒီးလဲၤဝဲဆူစၤဒၤအစီၤပၤဘၤရၤ, ဒီးဂမါရၤအစီၤပၤဘၤရၤစၤ, ဒီးဧးဒၤမါအစီၤပၤၡၤနး, ဒီးစဘၤဧၣ်အစီၤပၤၡၤမဘၤ, ဒီးဘၤလၤအစီၤပၤ, (လၢအမ့ၢ်စၤဧၣ်, ) ³ ပှၤအံၤခဲလၢာ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢကစၢၢ်ကလိစၤဒၤ, (မ့ၢ်ပီၣ်လဲၣ်ဃၣ်လီၤ. ) ⁴ ဒီးမၤစီၤကဒၤရလဧၤမ့ၤတဆံခံနံၣ်, ဒီးတဆံသၢနံၣ်န့ၣ်မၤကမၣ်တၢ်လီၤ. ⁵ ဒီးတဆံလွံၢ်နံၣ်န့ၣ်စီၤကဒၤရလဧၤမ့ၤဟဲဝဲ, ဒီးစီၤပၤတဖၣ်လၢအအိၣ်ဒီးအီၤ, ဒီးကျီကွံာ်ပှၤရၤဖၤဖိလၢဧၤစတၤရးကၤရနးပူၤ, ဒီးပှၤရှူၡံဖိလၢဃၣ်ပူၤ, ဒီးပှၤဧၤမ့လးဖိလၢကစၢၢ်ကလိကၤရၤတၤယၤပူၤ, ⁶ ဒီးပှၤဃၤရၤဖိလၢကစၢၢ်ဃံမၣ်အပူၤ, ဒီးစီၤၡၤရၤ, ဒီးဆူကီၢ်အၤရၤဘၤအပူၤလၢကီၢ်ကိာ်ပူၤလီၤ. ⁷ ဒီးဟဲက့ၤကဒါက့ၤ, ဒီးဟဲဝဲဆူဧၣ်မံးရှံး, (မ့ၢ်ကၤဒၤ, ) ဒီးထိၣ်ကွံာ်ပှၤဧၤမံၣ်ဖိအကီၢ်ခဲလၢာ်, ဒီးပှၤဧၤမံၣ်ဖိလၢအအိၣ်ထီၣ်လၢဃးစၣ်တၤမ့ၤလီၤ. ⁸ ဒီးစၤဒၤအစီၤပၤ, ဒီးဂမါရၤအစီၤပၤ, ဒီးဧၤဒမါအစီၤပၤ, ဒီးစဘၤဧၣ်အစီၤပၤ, ဒီးဘၤလၤအစီၤပၤ(မ့ၢ်စၤဧၣ်)ဟဲက့ၤဝဲ, ဒီးဒုးသုးလၢကစၢၢ်ကလိစၤဒ့ၣ်လီၤ. ⁹ ဒီးဧၤလၣ်အစီၤပၤကဒၤရလဧၣ်, ဒီးပှၤကလုာ်တဖၣ်အစီၤပၤတၤဒၤ, ဒီးၡၤနၣ်အစီၤပၤအၤမၤရဖၤ, ဒီးဧၤလၤၡၣ်အစီၤပၤအၤရၤဃး, စီၤပၤလွံၢ်ဂၤဆူစီၤပၤလွံၢ်ဂၤလီၤ. ¹⁰ ဒီးကစၢၢ်ကလိစၤဒ့ၣ်န့ၣ်အိၣ်ဒီးထံပူၤလၢသိလီၤ. ဒီးစၤဒၤ, ဒီးဂမါရၤအစီၤပၤတဖၣ်ဟဲစိာ်ဝဲ, ဒီးလီၤဃၢၤလၢအပူၤ, ဒီးပှၤအိၣ်ဖှိၣ်ရိဖှိၣ်န့ၣ်ဟဲစိာ်ဝဲဆူကစၢၢ်ကလိလီၤ. ¹¹ ဒီးပာ်ကွံာ်စၤဒၤ, ဒီးဂမါရၤအတၢ်မၤအသးခဲလၢာ်, ဒီးတၢ်မၤအသး, ဒီးဟဲက့ၤဝဲလီၤ. ¹² ဒီးဟဲစိာ်စီၤအၤဘရိၣ်အဖိခွါစီၤလၤလီၤ, ဒီးတၢ်မၤအသးတဖၣ်လီၤ. ဒီးစီၤအၤဘရိၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢစၤဒၤအပူၤလီၤ. ¹³ ဒီးစီၤအၤဘရိၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်ဒီးပှၤဧ့ၤဘြံၤဖိ, စီၤဧ့ၡကံၣ်, ဒီးစီၤဧၤနၢ်အပၢ်, ပှၤဧၤမ့လးဖိစီၤမၤမ့ၣ်, ဒီးအဝဲသ့ၣ်တဖၣ်မ့ၢ်စီၤအံၣ်စရ့လးအသးကညီၤလီၤ. ¹⁴ ဒီးတုၤစီၤအၤဘရိၣ်နၢၤလၢအပၢ်ဟဲစိာ်ကွံာ်အီၤဒီး, ဒုးအိၣ်ဖှိၣ်ရိဖှိၣ်အပၢ်အပၢ်တဖၣ်, ပှၤသၢကထိတဆံနွံဂၤ, လၢဟံၣ်ပူၤ, ဒီးဟဲစိာ်အီၤဆူဒၣ်လီၤ. ¹⁵ ဒီးကျဲထီၣ်ကွံာ်အီၤလၢမုၢ်ဟါ, ဒီးစီၤဒၤမ့ၤၡး, ဒီးပှၤတဖၣ်, ဒီးမၤသံအီၤ, ဒီးကျီကွံာ်အီၤ, ဒီးမၤသံအီၤဆူဃူဘၤ, လၢဒံၣ်စရ့လးအစုစၢၢ်ကလိလီၤ. ¹⁶ ဒီးဟဲစိာ်ကွံာ်တၢ်လိၤခဲလၢာ်, ဒီးဟဲစိာ်ကွံာ်အပၢ်စီၤလံး, ဒီးတၢ်လိၤ, ဒီးပှၤဂၤတဖၣ်, ဒီးပှၤကလုာ်တဖၣ်လီၤ. ¹⁷ ဒီးတုၤအဟဲက့ၤကဒါက့ၤလၢတၢ်မၤသံစီၤကဒၤရလဧၤမ့ၤ, ဒီးစီၤပၤတဖၣ်လၢအအိၣ်ဒီးအီၤဒီး, စၤဒၤအစီၤပၤဟဲစိာ်အီၤဆူစီၤပၤအကစၢၢ်ကလိအပူၤ, (န့ၣ်မ့ၢ်စၤဝၤအကစၢၢ်ကလိလီၤ. ) ¹⁸ ဒီးစီၤၡၤမ့ၤအစီၤပၤစီၤမံးလကၤၡဲဟဲစိာ်ကိၣ်, ဒီးစပံးထံလီၤ. ဒီးစီၤမံးလကၤၡဲမ့ၢ်ယွၤလၢအလိၤအစီၤပၤလီၤ. ¹⁹ ဒီးအုၣ်က့ၤခီၣ်က့ၤအီၤ, ဒီးစံးဝဲဒၣ်, မ်စီၤအၤဘရိၣ်, ပှၤဒိၣ်ဒိၣ်ကလဲာ်ယွၤ, ပှၤမၤယွၤဒီးဟီၣ်ခိၣ်န့ၣ်, ဟ့ၣ်တၢ်အုၣ်က့ၤခီၣ်က့ၤအီၤတက့ၢ်. ²⁰ ဒီးမ်ယွၤလၢအပာ်နဒုၣ်နဒါလၢနစုပူၤန့ၣ်, မ်အကဲထီၣ်တၢ်အုၣ်က့ၤခီၣ်က့ၤတက့ၢ်. ဒီးစီၤအၤဘရိၣ်ဟ့ၣ်အီၤတၢ်ခဲလၢာ်တဆံတဆံလီၤ. ²¹ ဒီးစီၤစၤဒၤအစီၤပၤစံးဝဲဒၣ်, ဟ့ၣ်ယၤလၢပှၤ, ဒီးဒုးဟဲစူၢ်က့ၤနသ့ၣ်ညါတၢ်တက့ၢ်. ²² ဒီးစီၤအၤဘရိၣ်စံးဝဲဒၣ်, ယကပာ်ယစုဆူယွၤ, ယွၤလၢအလိၤ, ပှၤမၤယွၤဒီးဟီၣ်ခိၣ်လီၤ. ²³ ဒီးယတဒုးဟဲစိာ်ဘၣ်နသးတဆံတဆံဘၣ်, ဒီးယတဒုးဟဲစိာ်ဘၣ်နသးတဆံတဆံဘၣ်, ဒ်သိးနသုတစံး, ယပာ်စီၤအၤဘရိၣ်လၢတၢ်လိၤလီၤ. ²⁴ မၤသးဒ်န့ၣ်ဒီးပှၤဖိခွါတဖၣ်မၤအသးန့ၣ်, ဒီးပှၤဟဲဝဲဒီးယၤ, စီၤအၤနး, ဒီးစီၤဧ့ၡကံၣ်, ဒီးစီၤမၤမ့ၤရၤ, မ်အယူာ်ထီၣ်အယူာ်လီၤ.
