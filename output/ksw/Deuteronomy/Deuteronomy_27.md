# Deuteronomy 27

¹ ဒီးစီၤမိၤရှ့, ဒီးစီၤအံၣ်စရ့လးအပၢ်တဖၣ်စံးဝဲဒၣ်, မၤသးဒ်န့ၣ်ဒီး, ပာ်လီၤသုသးလၢအယပာ်သုလၢမုၢ်မဆါတနံၤအံၤလီၤ. ² ဒီးတုၤသုဟဲစိာ်ယၤဒယၣ်ဆူကီၢ်အပူၤလၢယွၤနယွၤဟ့ၣ်နၤဒီး, သုဘၣ်ပာ်လၢၢ်အါဂၤ, ဒီးကိၢ်တၢ်ဂီၤအီၤဒီးကိၢ်တၢ်ဂီၤလီၤ. ³ ဒီးသုဘၣ်စံးလၢလၢၢ်တဖၣ်အပူၤတၢ်အုၣ်က့ၤခီၣ်က့ၤတၢ်အံၤခဲလၢာ်, ဒ်သိးသုကဟဲစိာ်ယံၣ်စရ့လး, ဒီးဟဲဆူကီၢ်လၢယွၤသုယွၤဟ့ၣ်သု, လၢထံဒီးထိၣ်ဟဲဝဲ, ဒ်ယွၤသုပၢ်တဖၣ်အယွၤစံးဝဲဒၣ်လၢသုလီၤ. ⁴ ဒီးတုၤသုဟဲစိာ်ယၤဒယၣ်ဒီး, သုဘၣ်ပာ်လၢၤတဖၣ်လၢကစၢၢ်ဧ့ဘံၣ်အပူၤ, ဒ်ယမၤလိာ်သုလၢမုၢ်မဆါတနံၤအံၤအသိးန့ၣ်, ဒီးသုဘၣ်ကိၢ်ထီၣ်အီၤဒီးကိၢ်တၢ်ဂီၤလီၤ. ⁵ ဒီးနဘၣ်မၤယွၤနယွၤလၢအပူၤတၢ်လုၢ်လီၢ်, တၢ်လုၢ်လီၢ်လၢလၢၤပူၤလီၤ. နဘၣ်မၤလၢၢ်လၢလၢၤပူၤဘၣ်. ⁶ ဒီးနဘၣ်မၤတၢ်လုၢ်လီၢ်လၢလၢၢ်တချုးချုးထီၣ်ဘၣ်, ဒီးနဘၣ်ပာ်တၢ်လုၢ်မ့ၣ်အူလၢအပူၤလၢယွၤနယွၤအဂီၢ်လီၤ. ⁷ ဒီးနဘၣ်မၤသံတၢ်အုၣ်က့ၤခီၣ်က့ၤလၢအပူၤ, ဒီးအီၣ်တၢ်, ဒီးသူၣ်ဖှံသးညီလၢယွၤနယွၤအပူၤလီၤ. ⁸ ဒီးစီၤစီလူးစံးဝဲဒၣ်, နဘၣ်ကွဲးလၢလၢၤပူၤတၢ်အုၣ်က့ၤခီၣ်က့ၤအံၤအတၢ်ကတိၤခဲလၢာ်, လၢတၢ်အုၣ်က့ၤခီၣ်က့ၤလီၤ. ⁹ ဒီးစီၤမိၤရှ့, ဒီးစီၤလ့ၤဝံအစီၤပၤတဖၣ်စံးဝဲဒၣ်လၢအံၣ်စရ့လးခဲလၢာ်, ဒီးစံးဝဲဒၣ်, ဃၣ်နသး, ဒီးနၢၤနသးတက့ၢ်, အံၣ်စရ့လးဧၢ. မုၢ်မဆါတနံၤအံၤနကဲထီၣ်ယွၤနယွၤအပှၤလီၤ. ¹⁰ ဒီးနဘၣ်နၢၤယွၤနယွၤအတၢ်သံ, ဒီးမၤတၢ်ခဲလၢာ်, ဒီးတၢ်အုၣ်က့ၤခီၣ်က့ၤလၢအယပာ်နၤလၢမုၢ်မဆါတနံၤအံၤလီၤ. ¹¹ ဒီးစီၤမိၤရှ့စံးဝဲဒၣ်, လၢမုၢ်မဆါတနံၤအံၤ, စီၤၡံၡးမၤလိာ်ပှၤ, ဒီးစံးဝဲဒၣ်, ¹² ဒီးသုဘၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢကစၢၢ်ကလိရိၤ, လၢသုကလဲၤဝဲဆူယံၤဒၣ်အပူၤ, ဒ်သိးသုကအုၣ်က့ၤခီၣ်က့ၤပှၤလီၤ. စီၤစူၤရံ, ဒီးစီၤလ့ၤဝံ, ဒီးစီၤယူဒၤ, ဒီးစီၤယံးစကၤ, ဒီးစီၤယၤစိာ်, ဒီးစီၤဘံၣ်ယၤမ့လးလီၤ. ¹³ မၤသးဒ်န့ၣ်ဒီးသုဘၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢကစၢၢ်ဧ့ဘံၣ်အဂီၢ်, ဒ်သိးသုကစံးတၢ်သံလီၤ. စီၤရၤဘၤ, ဒီးစီၤကး, ဒီးစီၤအၤရှံၤ, ဒီးစီၤစဘူံၣ်, ဒီးစီၤဒၣ်, ဒီးစီၤနးဖၤလၤလီၤ. ¹⁴ ဒီးပှၤလ့ၤဝံဖိဘၣ်စံးဆၢတၢ်, ဒီးစံးဝဲဒၣ်လၢပှၤအံၣ်စရ့လးဖိခဲလၢာ်, ဒီးစံးဝဲဒၣ်, ¹⁵ ပှၤလၢအမၤတၢ်လုၢ်တၢ်လိၤ, ဒီးတၢ်ထူတၢ်ထူ, တၢ်ဂ့ၤလၢယွၤအဂီၢ်, ပှၤမၤတၢ်ဖိအစုမၤတၢ်, ဒီးပာ်ကွံာ်အီၤလၢတၢ်ကိၢ်တၢ်ဂီၤန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ¹⁶ ပှၤမၤသံအပၢ်မ့ၢ်ဂ့ၤ, အပၢ်မ့ၢ်ဂ့ၤန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ¹⁷ ဒီးပှၤခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ¹⁸ ပှၤဟဲစိာ်ပှၤသူၣ်ဖှံသးညီလၢကျဲပူၤန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ¹⁹ မ့ၢ်မတၤမၤကလီကလီပှၤအိၣ်ဘှံးဖိ, ဒီးပှၤဖိခွါဖိ, ဒီးပှၤမါဖိ, တၢ်မၤသံအီၤဒီး, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမါလီၤ. ²⁰ ပှၤအိၣ်ဘှီၣ်ကလာ်ဒီးအပၢ်အမါန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. မ့ၢ်အဒုးကဲထီၣ်အပၢ်အကူလီၤ. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမါလီၤ. ²¹ ဒီးပှၤခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ²² ပှၤအိၣ်ဘှီၣ်ကလာ်အပၢ်အဖိခွါ, ဒီးအပၢ်အဖိခွါတဂၤန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ²³ ဒီးပှၤခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ²⁴ ပှၤမၤသံအပၢ်လၢသးဝးတရံးန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤကညီခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ²⁵ ပှၤမၤသံပှၤတတီတလိၤန့ၣ်, မ်အမၤသံကွံာ်အီၤတက့ၢ်. ဒီးပှၤခဲလၢာ်ကစံး, အၤမၢ်လီၤ. ²⁶ ပှၤလၢအတမၤဘၣ်တၢ်အုၣ်က့ၤခီၣ်က့ၤအံၤအတၢ်ကတိၤ, ဒ်သိးအကမၤအီၤန့ၣ်, မ်အမၤသံအီၤတက့ၢ်. ဒီးပှၤခဲလၢာ်ကစံး, အၤမါလီၤ.
