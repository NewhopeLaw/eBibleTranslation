# Psalms 81

¹ တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢစီၤအၤစၤအဂီၢ်, တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢစီၤအၤစၤအဂီၢ်, တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢစီၤအၤစၤအဂီၢ်, ² အံၣ်စရ့လးဧၢ, စံးဝဲဒၣ်, ဃ့ကညးပယွၤတက့ၢ်. ဃ့ကညးစီၤယၤကိာ်အယွၤတက့ၢ်. ³ ပျုၤတၢ်, ပျၤတၢ်ဆူး, ဒီးထးခိၣ်တဘိ, ဒီးသိတဘိလီၤ. ⁴ ဒီးလၢနံၣ်လၤခိၣ်, ဒီးလၢနံၣ်လၤလိၤ, ဒီးလၢမုၢ်မဆါတနံၤအံၤ, ပျၢ်ထးခိၣ်တက့ၢ်. ⁵ မ့ၢ်အံၣ်စရ့လးအတၢ်သိၣ်တၢ်သီ, ဒီးစီၤယၤကိာ်အယွၤတၢ်အၢၣ်လီၤအီလီၤလီၤ. ⁶ မၤသးဒ်တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢစီၤယၤစိာ်အပူၤအသိးန့ၣ်, ဒီးဟဲစိာ်အီၤလၢကီၢ်အဲၤကူပတူးပူၤ, ဒီးနၢၤတၢ်လၢအတသ့ၣ်ညါဘၣ်အတၢ်ကတိၤလီၤ. ⁷ ယကပာ်ကွံာ်တၢ်လုၢ်လၢအပျုၤပူၤ, ဒီးအစုအိၣ်ဘှီၣ်ကလာ်လၢတၢ်ပှၢၤပူၤလီၤ. ⁸ ဒီးလၢတၢ်ဒုၣ်ဒွဲၣ်အပူၤနစံးဝဲဒၣ်, ဒီးယကပာ်ထီၣ်ထီနၤလီၤ. ယနၢၤနတၢ်သံလၢထံထီၣ်ထီအပူၤ, ယကသ့ၣ်ညါနၤလၢထံမ့ၤဘၤအပူၤ, စၤလၤလီၤ. ⁹ ယစီၤပၤဧၢ, ကိၢ်တၢ်ဂီၤတက့ၢ်. ဒီးယကစံးလၢသုလီၤ. အံၣ်စရ့လးဧၢ, ယကစံးလၢသုလီၤ. မ့ၢ်သုကကိၢ်တၢ်ဂီၤဒီး, ယကစံးလၢသုလီၤ. ¹⁰ ယွၤတဂၤန့ၣ်တကဲထီၣ်ဘၣ်လၢသုပူၤဘၣ်, ဒီးသုတဃၢၤဘၣ်ယွၤတဂၤဘၣ်. ¹¹ ယကမ့ၢ်ယွၤနယွၤလၢအဟဲစိာ်နၤလၢကီၢ်အံၣ်စရ့လးလီၤ. ပှီၢ်နထးခိၣ်ကလီကလီတက့ၢ်. ဒီးယကပာ်လီၤကွံာ်အီၤလီၤ. ¹² ဘၣ်ဆၣ်ဒီးယပှၤတနါဘၣ်ယတၢ်သံဘၣ်, ဒီးအံၣ်စရ့လးတမၤဘၣ်ယၤဘၣ်. ¹³ ဒီးယကဒုးဟဲက့ၤအီၤဒ်အသးကိာ်အသိးန့ၣ်, ဒီးဟဲက့ၤဝဲဒ်အတၢ်ကတိၤအသိးလီၤ. ¹⁴ ပှၤကနၢၤယၤဒီး, အံၣ်စရ့လးကလဲၤလၢယကျဲန့ၣ်ဒီး, ¹⁵ ယကပာ်ယစုဆူအဒုၣ်ဒွဲၣ်အပူၤ, ဒီးယကပာ်ယစုလၢပှၤမၤဟးဂီၤအီၤအပူၤလီၤ. ¹⁶ ပှၤသးကညီၤယွၤန့ၣ်ကမၤဟးဂီၤအီၤ, ဒီးအနံၣ်န့ၣ်ကလီၤထူလီၤယိာ်လီၤ. ¹⁷ ဒီးယကပာ်ကွံာ်အီၤလၢသိအဆီ, ဒီးယကပာ်ခူသူၣ်အီၤလၢသိလၢကစၢၢ်ကလိလီၤ.
