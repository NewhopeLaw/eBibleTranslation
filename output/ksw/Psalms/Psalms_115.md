# Psalms 115

¹ ယွၤဧၢ, တမ့ၢ်ဘၣ်ပဘၣ်, တမ့ၢ်ဘၣ်ပဘၣ်, ဘၣ်ဆၣ်ဒီးဟ့ၣ်လၤကပီၤလၢနဟံၣ်အဂီၢ်, နတၢ်အုၣ်က့ၤခီၣ်က့ၤအဃိ, ဒီးနတၢ်တီတၢ်လိၤအဃိတက့ၢ်. ² ပှၤကလုာ်တဖၣ်ကစံး, အယွၤမ့ၢ်ဖဲလဲၣ်န့ၣ်, မ့ၢ်အဘၣ်မနုၤအဃိလဲၣ်. ³ ပယွၤမ့ၢ်လၢဟီၣ်ခိၣ်ချၢလီၤ. မ့ၢ်အမၤဒ်အသးဘၣ်အသိးန့ၣ်လီၤ. ⁴ အလုၢ်အဒိၣ်တဖၣ်မ့ၢ်သိဒီးထူ, ပှၤအစုမၤအီၤလီၤ. ⁵ အစုမ့ၢ်အစု, ဒီးတစံးဘၣ်. အသူၣ်မ့ၢ်အသး, ဒီးတသ့ၣ်ညါဘၣ်. ⁶ ဃၣ်အိၣ်, ဒီးတနၢၤဘၣ်. ဃၣ်အိၣ်, ဒီးတမံဘၣ်. ⁷ အစုမ့ၢ်အစု, ဒီးတထိၣ်ဘၣ်အီၤဘၣ်. အလိၤမ့ၢ်အလိၤ, ဒီးတဟဲဘၣ်အီၤဘၣ်. တမၤသံဘၣ်အစုပူၤဘၣ်. ⁸ ပှၤမၤအီၤတဖၣ်, ဒီးကယဲၢ်ပှၤကွၢ်သိအီၤတဖၣ်, မ့ၢ်ဒ်အီၤအသိးလီၤ. ⁹ အံၣ်စရ့လးဧၢ, သ့ၣ်ညါယွၤတက့ၢ်. အဝဲဒၣ်မ့ၢ်အလုၢ်အဒိၣ်, ဒီးကစၢၢ်ကလိလီၤ. ¹⁰ စီၤအၤဟရိၣ်ဟံၣ်ဖိဧၢ, သ့ၣ်ညါယွၤတက့ၢ်. အဝဲဒၣ်မ့ၢ်သုတၢ်အုၣ်က့ၤခီၣ်က့ၤ, ဒီးသုကစၢၢ်ကလိလီၤ. ¹¹ ပှၤသးကညီၤယွၤတဂၤဧၢ, ပာ်နသးဆူယွၤတက့ၢ်. အဝဲဒၣ်မ့ၢ်နတၢ်အုၣ်က့ၤခီၣ်က့ၤ, ဒီးနကစၢၢ်ကလိလီၤ. ¹² မ်ယွၤသ့ၣ်ညါပတၢ်, ဒီးမၤကမၣ်ပတၢ်တက့ၢ်. မ်အမၤလိၤအံၣ်စရ့လးအဟံၣ်, ဒီးမၤလိၤစီၤအၤဟရိၣ်အဟံၣ်တက့ၢ်. ¹³ အဝဲဒၣ်ကအုၣ်က့ၤခီၣ်က့ၤပှၤသူၣ်ဖှံသးညီ, ပှၤအါဂၤဒီးပှၤအါဂၤလီၤ. ¹⁴ မ်ယွၤပာ်ထီၣ်ထီသု, သု, ဒီးသုဖိခွါတဖၣ်တက့ၢ်. ¹⁵ မ်ယွၤလၢအမၤမူခိၣ်ဒီးဟီၣ်ခိၣ်န့ၣ်, ဟ့ၣ်သုတၢ်အုၣ်က့ၤခီၣ်က့ၤတက့ၢ်. ¹⁶ မူခိၣ်မ့ၢ်ယွၤအလိၤလီၤ. ဘၣ်ဆၣ်ဒီးဟီၣ်ခိၣ်န့ၣ်ဟ့ၣ်အီၤလၢပှၤကညီဖိလီၤ. ¹⁷ ပှၤသံတဖၣ်တအုၣ်က့ၤခီၣ်က့ၤဘၣ်ယွၤဘၣ်, ဒီးပှၤဟဲက့ၤဆူတၢ်သံအလိၤန့ၣ်တမၤကမၣ်ဘၣ်အီၤဘၣ်. ¹⁸ ဘၣ်ဆၣ်ဒီးပကအုၣ်က့ၤခီၣ်က့ၤယွၤလၢမုၢ်မဆါတနံၤအံၤ, ဒီးလၢအလိၤလီၤ. အၤလၤလယၤဧၢ.
