# Psalms 111

¹ မၤသးစီဆှံယွၤတက့ၢ်. ယကအုၣ်က့ၤခီၣ်က့ၤယွၤလၢယသးတလိၤ, လၢပှၤတီပှၤလိၤအစုပူၤ, ဒီးလၢဟီၣ်ခိၣ်ချၢအပူၤလီၤ. ² ယွၤတၢ်မၤန့ၣ်ဒိၣ်လီၤ. ပှၤမၤအသးလၢအပူၤခဲလၢာ်ကသ့ၣ်ညါအီၤလီၤ. ³ အတၢ်မၤန့ၣ်ကလီကလီ, ဒီးကလီကလီလီၤ. ဒီးတၢ်တီတၢ်လိၤန့ၣ်လီၤထူလီၤယိာ်လီၤ. ⁴ ပာ်ထီၣ်ထီတၢ်ဂ့ၤတၢ်ဝါလီၤ. ယွၤမ့ၢ်တၢ်အုၣ်က့ၤခီၣ်က့ၤတၢ်, ဒီးတၢ်အုၣ်က့ၤခီၣ်က့ၤတၢ်လီၤ. ⁵ ဟ့ၣ်ကိၢ်တၢ်ဂီၤလၢပှၤသးကညီၤအီၤတဖၣ်, ဒီးကွၢ်ဆၢၣ်မဲာ်တၢ်အၢၣ်လီၤအီလီၤလီၤထူလီၤယိာ်လီၤ. ⁶ မၤသးဒ်န့ၣ်ဒီးစံးဝဲဒၣ်, အမၤအသးအခိၣ်န့ၣ်, မ့ၢ်အဟ့ၣ်ပှၤကလုာ်တဖၣ်အလိၤလီၤ. ⁷ အစုမၤတၢ်န့ၣ်မ့ၢ်တၢ်တီတၢ်လိၤ, ဒီးတၢ်တီတၢ်လိၤလီၤ. အတၢ်အုၣ်က့ၤခီၣ်က့ၤခဲလၢာ်မ့ၢ်တၢ်တီတၢ်လိၤလီၤ. ⁸ မၤသးဒ်န့ၣ်ဒီး, ပှၤန့ၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လီၤထူလီၤယိာ်လီၤ. မၤသးဒ်တၢ်တီတၢ်လိၤ, ဒီးတၢ်တီတၢ်လိၤအသိးလီၤ. ⁹ ဒုးဟဲစိာ်တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢပှၤအဂီၢ်, ပာ်ထီၣ်ထီတၢ်အၢၣ်လီၤအီလီၤလီၤထူလီၤယိာ်လီၤ. အပၢ်မ့ၢ်ယွၤ, ဒီးအသးကိၢ်အသးဂီၤလီၤ. ¹⁰ တၢ်အုၣ်က့ၤခီၣ်က့ၤယွၤန့ၣ်မ့ၢ်တၢ်အုၣ်က့ၤခီၣ်က့ၤအခိၣ်လီၤ. တၢ်ကူၣ်တၢ်ဆးန့ၣ်မ့ၢ်တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢအမၤအီၤခဲလၢာ်လီၤ. တၢ်အုၣ်က့ၤခီၣ်က့ၤအီၤန့ၣ်အိၣ်လီၤထူလီၤယိာ်လီၤ.
