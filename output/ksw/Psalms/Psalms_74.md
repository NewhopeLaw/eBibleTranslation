# Psalms 74

¹ ယွၤဧၢ, နစွါထီၣ်ယၤလၢမုၢ်တနံၤန့ၣ်မနုၤအဃိလဲၣ်. နသးကိၢ်နသးကညီၤတၢ်ဖိၣ်လၢအမၤဘျါက့ၤအီၤန့ၣ်မနုၤအဃိလဲၣ်. ² မၤသးဒ်န့ၣ်ဒီး, သ့ၣ်ညါနပှၤလၢအပာ်ထီၣ်ထီကွံာ်အီၤလၢမုၢ်ဟါ, ပှၤကလုာ်လၢနပာ်ထီၣ်ထီကွံာ်အီၤ, ကစၢၢ်စၤယၣ်လၢနအိၣ်ဖှိၣ်ရိဖှိၣ်လီၤ. ³ ပာ်ထီၣ်ထီနသး, ဒ်သိးနကထိၣ်ကဒါက့ၤအခိၣ်သလုးတဖၣ်, ပှၤဒုၣ်ဒွဲၣ်အတၢ်ကမၣ်ခဲလၢာ်လၢဟီၣ်ခိၣ်အခိၣ်သလုးအပူၤတက့ၢ်. ⁴ နဒုၣ်နဒါမၤသံတၢ်, ဒီးပာ်အခိၣ်သလုးလၢနမုၢ်မဆါတနံၤအံၤ, ဒီးပာ်အခိၣ်သလုးလၢတၢ်အုၣ်က့ၤခီၣ်က့ၤအဂီၢ်လီၤ. ⁵ မၤသးဒ်ပှၤဟဲထီၣ်ဆူဟီၣ်ခိၣ်အသိးန့ၣ်, ဒီးမၤကိၢ်တၢ်ဂီၤဒ်ပှၤခၢၣ်သးလၢကီၢ်ပူၤအသိးန့ၣ်လီၤ. ⁶ ဒီးခဲကနံၣ်အံၤ, ဃၣ်ကွံာ်အပဲတရီတဖၣ်တပူၤဃီလီၤ. ဃၣ်ကွံာ်အီၤဒီးသိ, ဒီးဘိလီၤ. ⁷ ဒီးပာ်မ့ၣ်အူလၢနကီၢ်ခိၣ်ပူၤ, ဒီးပာ်ကလီကလီနဟံၣ်လၢဟီၣ်ခိၣ်ချၢလီၤ. ⁸ စံးလၢအသးကံၢ်ပူၤ, မ်ပမၤသံအီၤခဲလၢာ်လီၤ. မ်ပမၤသံလီၤမ့ၣ်အူယွၤအကလုာ်ခဲလၢာ်လၢဟီၣ်ခိၣ်ချၢလီၤ. ⁹ ပသ့ၣ်ညါတၢ်အုၣ်က့ၤခီၣ်က့ၤဘၣ်, ဒီးဝံတအိၣ်ဘၣ်, ဒီးတၢ်အံၤကကဲထီၣ်အနံၣ်တဆံလဲၣ်န့ၣ်ပသ့ၣ်ညါဘၣ်. ¹⁰ ယွၤဧၢ, နဒုၣ်နဒါကပာ်ကလီကလီနသး, နဒုၣ်နဒါကပာ်ကလီကလီနသးတပူၤဃီလဲၣ်. ¹¹ နဒုးဟဲထီၣ်နစု, နစုဒိၣ်လၢနစုပူၤလီၤထူလီၤယိာ်န့ၣ်မနုၤအဃိလဲၣ်. ¹² ဘၣ်ဆၣ်ဒီးယွၤမ့ၢ်ပစီၤပၤလၢမုၢ်ဟါလီၤ. မၤတၢ်အုၣ်က့ၤခီၣ်က့ၤလၢဟီၣ်ခိၣ်ချၢလီၤ. ¹³ နပာ်ပၢၤပီၣ်လဲၣ်လၢနဂံၢ်နဘါ, နမၤကိၢ်တၢ်ဂီၤသိအခိၣ်လၢထံပူၤလီၤ. ¹⁴ နမၤကိၢ်တၢ်ဂီၤပှၤလၤဝၤဖိအခိၣ်, နဟ့ၣ်အီၤဒ်သိးအကဒုးအီၣ်တၢ်လၢဟီၣ်ခိၣ်ချၢအပၢ်တဖၣ်အဂီၢ်လီၤ. ¹⁵ နဖှံထီၣ်ထံပူၤ, ဒီးထံခိၣ်, နမၤကိၢ်တၢ်ဂီၤထံပူၤလၢအဟဲဝဲလီၤထူလီၤယိာ်လီၤ. ¹⁶ မုၢ်တနံၤမ့ၢ်နသး, ဒီးမုၢ်တနံၤမ့ၢ်နသးလီၤ. နမၤမုၢ်ဒီးလါလီၤ. ¹⁷ နမၢလီၤဟီၣ်ခိၣ်အခိၣ်သလုးခဲလၢာ်လီၤ. နပာ်ထီၣ်ထီမုၢ်ဟါ, ဒီးမုၢ်ဆ့ၣ်ထီၣ်လီၤ. ¹⁸ တၢ်အံၤကွၢ်ကွၢ်, နဒုၣ်နဒါမၤဟးဂီၤနသး, စီၤပၤတဖၣ်မၤဟးဂီၤနပၢ်လီၤ. ¹⁹ ဟ့ၣ်ပှၤအုၣ်က့ၤခီၣ်က့ၤနၤလၢအသးန့ၣ်လၢဟီၣ်ခိၣ်အကမူၣ်အဂီၢ်ဘၣ်. မ်နသုတသးပၢၤဘၣ်နပှၤဒုၣ်ဒွဲၣ်အသးလီၤထူလီၤယိာ်ဘၣ်. ²⁰ ကွၢ်နတၢ်အုၣ်က့ၤခီၣ်က့ၤတက့ၢ်. ယွၤဧၢ, ပှၤမၤကမၣ်တၢ်တဖၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢဟီၣ်ခိၣ်ချၢလီၤ. ²¹ မ်ပှၤသူၣ်ဖှံသးညီန့ၣ်တဟဲက့ၤကဒါက့ၤဘၣ်, ဒီးမ်ပှၤမၤကမၣ်တၢ်န့ၣ်တမၤကိၢ်တၢ်ဂီၤဘၣ်. မ်ပှၤသူၣ်ဖှံသးညီ, ဒီးပှၤသူၣ်ဖှံသးညီန့ၣ်မၤလၤကပီၤနကလုာ်တက့ၢ်. ²² ယွၤဧၢ, အိၣ်ဖှိၣ်ရိဖှိၣ်, ဒီးဟ့ၣ်တၢ်ကူၣ်တၢ်ဆးတက့ၢ်. မၤသးဒ်န့ၣ်ဒီးကွၢ်ကွၢ်, နပာ်နသးကိၢ်နသးဂီၤလၢပှၤတီပှၤလိၤအဃိလၢမုၢ်မဆါတနံၤအံၤတက့ၢ်. ²³ မ်နသးကိၢ်တၢ်ဂီၤအသံန့ၣ်နသးကိၢ်တၢ်ဂီၤဘၣ်. မ်ပှၤဒုၣ်ဒွဲၣ်နၤတဖၣ်အသူၣ်ဖှံသးညီန့ၣ်ကဟဲထီၣ်ဆူနဂီၢ်လီၤ.
