# Psalms 23

¹ ယွၤမ့ၢ်ယပှၤလုၢ်တၢ်အဒိၣ်လီၤ. ယကဘၣ်ဘၣ်တၢ်နီတဂၤဘၣ်. ² ပာ်ယၤလီၤဃၢၤလၢထံပူၤ, ပာ်ယၤဆူထံပူၤလီၤဃၢၤလီၤ. ³ ပာ်ကလီကလီယသးလီၤ. ဒုးဟဲထီၣ်ယၤလၢတၢ်တီတၢ်လိၤအကျဲအပူၤ, အပၢ်အတၢ်အဃိလီၤ. ⁴ မ့ၢ်ယဟဲလၢကစၢၢ်ကလိလၢအသးဝံၣ်န့ၣ်ဒီး, ယကကွၢ်ဆၢၣ်မဲာ်တၢ်ကမၣ်ဘၣ်. ယွၤဧၢ, နမ့ၢ်ဒီးယၤလီၤ. နဘိ, ဒီးနခိၣ်နါ, မ့ၢ်အပာ်ယသးလီယသးလီၤ. ⁵ နပာ်စၢၢ်ကလိလၢယပူၤလၢယဒုၣ်ယဒါတဖၣ်အသးကိာ်ပူၤလီၤ. နစိာ်ယခိၣ်လၢသိ, ဒီးယထးခိၣ်ကလီကလီလီၤ. ⁶ မၤသးဒ်န့ၣ်ဒီးတၢ်ဂ့ၤ, ဒီးတၢ်အုၣ်က့ၤခီၣ်က့ၤကဟဲစိာ်ယၤလၢမုၢ်မဆါတနံၤအံၤ, ဒီးယကအိၣ်ဘှံးလၢယွၤဟံၣ်ပူၤလၢမုၢ်မဆါတနံၤအံၤလီၤ.
