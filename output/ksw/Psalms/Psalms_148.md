# Psalms 148

¹ ယွၤဧၢ, ဂုၤဂုၤယွၤတက့ၢ်. ဂုၤဂုၤယွၤလၢဟီၣ်ခိၣ်ချၢတက့ၢ်. ဂုၤဂုၤအီၤလၢဟီၣ်ခိၣ်ချၢတက့ၢ်. ² အပျုၤခဲလၢာ်ဧၢ, ဂုၤဂုၤအီၤတက့ၢ်. အသုးမုၢ်ခဲလၢာ်ဧၢ, ဂုၤဂုၤအီၤတက့ၢ်. ³ ယွၤဧၢ, တၢ်အုၣ်က့ၤခီၣ်က့ၤအီၤတက့ၢ်. မုၢ်ဒီးလါဧၢ. တၢ်လုၢ်တၢ်ဒိၣ်ခဲလၢာ်ဧၢ! ⁴ မူခိၣ်အပျုၤတဖၣ်, ဒီးထံလၢဟီၣ်ခိၣ်အပူၤတဖၣ်ဧၢ, မၤသးစီဆှံအီၤတက့ၢ်. ⁵ မ်အအုၣ်က့ၤခီၣ်က့ၤယွၤအမံၤတက့ၢ်. ဘၣ်ဆၣ်ဒီးစံးဝဲဒၣ်, ဒီးကဲထီၣ်ဝဲလီၤ. ⁶ ဒီးပာ်ထီၣ်ထီအီၤတပူၤဃီလီၤ. ပာ်ထီၣ်ထီတၢ်အၢၣ်လီၤအီလီၤလၢအတဟဲထီၣ်ဘၣ်လီၤ. ⁷ လုၢ်ယွၤလၢဟီၣ်ခိၣ်ချၢတက့ၢ်. ဆၣ်ဖိကီၢ်ဖိ, ဒီးဟီၣ်ခိၣ်အလိၤခဲလၢာ်ဧၢ. ⁸ မ့ၣ်အူ, ဒီးမ့ၣ်အူဃၣ်, ကစၢၢ်ကလိ, ဒီးကစၢၢ်ကလိ, ကစၢၢ်ကလိလၢအမၤအတၢ်ကတိၤလီၤ. ⁹ ကစၢၢ်ကလိ, ဒီးတၢ်ကလာ်ခဲလၢာ်, ကျဲအလိၤ, ဒီးတၢ်ကၤရးခဲလၢာ်ဧၢ, ¹⁰ တိၢ်ကူးတဖၣ်, ဒီးတၢ်မၤအသးခဲလၢာ်, ဒီးတၢ်ဟဲစိာ်တဖၣ်, ဒီးသိလၢအပျၢ်လီၤ. ¹¹ လၢဟီၣ်ခိၣ်အစီၤပၤတဖၣ်, ဒီးပှၤကလုာ်တဖၣ်ခဲလၢာ်, ပှၤခိၣ်ဖိ, ဒီးဟီၣ်ခိၣ်အပၢ်တဖၣ်ခဲလၢာ်ဧၢ, ¹² ပှၤဖိၣ်ဖိၣ်, ဒီးပှၤဖိၣ်ဖိၣ်, ပှၤခိၣ်ဖိ, ဒီးပှၤဖိၣ်ဖိၣ်လီၤ. ¹³ မ်ပှၤအုၣ်က့ၤခီၣ်က့ၤယွၤအကလုၢ်တက့ၢ်. မ့ၢ်အစီၤပၤတဂၤဃီလီၤ. အတၢ်သးဝံၣ်အိၣ်ဖှိၣ်ရိဖှိၣ်လၢဟီၣ်ခိၣ်ချၢ, ဒီးလၢဟီၣ်ခိၣ်ချၢလီၤ. ¹⁴ ဒီးပာ်ထီၣ်ထီအခိၣ်သလုးလၢအပှၤကညီအဂီၢ်, တၢ်အုၣ်က့ၤခီၣ်က့ၤလၢပှၤတီပှၤလိၤခဲလၢာ်အဂီၢ်, လၢပှၤအံၣ်စရ့လးဖိအဂီၢ်, ပှၤကညီလၢအအိၣ်ဝးတရံးအီၤအဂီၢ်လီၤ. အုၣ်က့ၤခီၣ်က့ၤယွၤတက့ၢ်.
