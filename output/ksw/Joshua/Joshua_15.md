# Joshua 15

¹ ဒီးယူဒၤဖိတကီၢ်ခါအစုပူၤ, ဒ်အပၢ်တဖၣ်အသိးန့ၣ်, မၤသးဒ်ဧၤဒံၣ်အကီၢ်ဃၣ်ပူၤလၢကီၢ်ကိာ်စူၤရံအပူၤ, လၢမုၢ်ဆ့ၣ်ထီၣ်, လၢမုၢ်ဆ့ၣ်ထီၣ်အခိၣ်ပူၤလီၤ. ² ဒီးအကီၢ်ဃၢၤလၢမုၢ်ဆ့ၣ်နီၤန့ၣ်မ့ၢ်လၢပီၣ်လဲၣ်သံအခိၣ်, လၢကီၢ်အခိၣ်လၢအဟဲဝဲဆူမုၢ်ဆ့ၣ်နီၤအပူၤလီၤ. ³ ဒီးလဲၤဝဲဆူမၤလၤဧကၤရဘ့လး, ဒီးဟဲဝဲဆူၡၣ်, ဒီးဟဲဝဲဆူကၤဒၤဘၤနါ, ဒီးဟဲဝဲဆူဃၡၤရၤ, ဒီးဟဲဝဲဆူဧဒၤ, ဒီးဟဲဝဲဆူကၤကၤ, ⁴ ဒီးလဲၤဝဲဆူအၤစယၤ, ဒီးဟဲဝဲဆူထံအဲၤကူပတူးအထံ, ဒီးဟဲဝဲဆူမုၢ်ထီၣ်ပူၤလီၤ. မ့ၢ်အကီၢ်ဃၢၤလၢမုၢ်ထီၣ်ပူၤလီၤ. ⁵ ဒီးအကီၢ်ဃၢၤလၢမုၢ်ထီၣ်န့ၣ်မ့ၢ်ပီၣ်လဲၣ်သံလၢယၤဒၤအခိၣ်လီၤ. ဒီးအကီၢ်ဃၢၤလၢမုၢ်ထီၣ်န့ၣ်မ့ၢ်ပီၣ်လဲၣ်အခိၣ်လၢယၤဒၤအခိၣ်လီၤ. ⁶ ဒီးကီၢ်ပူၤန့ၣ်ဟဲထီၣ်ဆူဘ့ၤသဃၣ်နး, ဒီးလဲၤဝဲဆူဘၤသဧရၤဘၤ, ဒီးဟဲလီၤဆူဘံၣ်ယၤမ့လးစီၤရူၤၡၢ်အခဲလီၤ. ⁷ ဒီးကီၢ်ပူၤန့ၣ်ဟဲထီၣ်ဆူဒဘၤရိၣ်လၢကစၢၢ်ကလိအၤဃၣ်, ဒီးဃၣ်ထီၣ်ဆူကၤလကၤလၢကၤလကၤအပူၤ, ဘၣ်ဃးဒီးတၢ်ဟဲထီၣ်ဆူဧၤဒူမ့လးအပူၤလၢကီၢ်က့ၣ်ပူၤ, ဒီးကီၢ်ပူၤန့ၣ်ဟဲထီၣ်ဆူထံအၤနၡမ့ၤ, ဒီးအိၣ်ထီၣ်လၢဧၤယံးရဃၤလီၤ. ⁸ ဒီးကီၢ်ဃၣ်န့ၣ်ဟဲဝဲဆူပှၤဘံၣ်ယၤမံၣ်ဖိအကစၢၢ်ကလိ, လၢပှၤယဘၤဧၤဖိအကစၢၢ်ကလိ, (မ့ၢ်ယရူၤၡယၤလီၤ. ) ဒီးကစၢၢ်ကလိဟဲထီၣ်ဆူကစၢၢ်ကလိအခိၣ်လၢအကွၢ်ဝဲဆူကစၢၢ်ကလိဟၤနၣ်လၢမုၢ်ထီၣ်အပူၤ, လၢကစၢၢ်ကလိရဖၤအခိၣ်လၢမုၢ်ထီၣ်အပူၤလီၤ. ⁹ ဒီးကစၢၢ်ကလိဟဲက့ၤလၢကစၢၢ်ကလိအခိၣ်ဆူနံးဖၤအထံပူၤ, ဒီးဟဲက့ၤဆူကစၢၢ်ဧ့ဖၤရၣ်အကီၢ်တဖၣ်, (လၢအမ့ၢ်ဘဧၤလၤ, ပှၤယဘူၤဖိအကီၢ်လီၤ. ) ¹⁰ ဒီးကီၢ်ဃၣ်ထီၣ်လၢဘဧၤလၤအပူၤဆူမုၢ်ထီၣ်ဆူကစၢၢ်စၤဧၤရိၣ်, ဒီးဟဲဝဲဆူကစၢၢ်ယဧၤရ့လးအခိၣ်, (မ့ၢ်ကၡလၣ်, ) ဒီးဟဲဝဲဆူဘ့ၤသၡမါ, ဒီးဟဲဝဲဆူတၤမါလီၤ. ¹¹ ဒီးကီၢ်ဃၣ်န့ၣ်ဟဲဝဲဆူဧကၤရၣ်အခိၣ်လၢမုၢ်ထီၣ်, ဒီးကီၢ်ဃၣ်န့ၣ်ဟဲဝဲဆူၡကၤရၣ်, ဒီးဟဲဝဲဆူကစၢၢ်ဘဧၤလၤ, ဒီးဟဲဝဲဆူယဘၤနဧၤ, ဒီးအိၣ်ထီၣ်လၢမုၢ်ထီၣ်လီၤ. ¹² ဒီးပှၤယူဒၤဖိအကီၢ်ဝးတရံးလၢပီၣ်လဲၣ်ပူၤ, ဒီးလၢအကီၢ်ဝးတရံးန့ၣ်မ့ၢ်ပှၤယူဒၤဖိအကီၢ်ဝးတရံး, ဒ်အကီၢ်တဖၣ်အသိးလီၤ. ¹³ ဒီးဟ့ၣ်စီၤယဖံနါစီၤကၤလဘၤလၢယူဒၤဖိအပူၤ, ဒ်ယွၤစံးဝဲဒၣ်လၢစီၤယၤရှူၤအသိးန့ၣ်, ပှၤဧၤနးဖိအပၢ်စီၤအၤဘၤ, စီၤကၤရၤဧၤဘၤ, (မ့ၢ်စီၤဃဘၤရၣ်လီၤ. ) ¹⁴ ဒီးစီၤကၤလၤဒုးဟဲစိာ်ပှၤဧၤနးဖိစီၤရှ့ၡၤ, ဒီးစီၤအၤဃံမၣ်, ဒီးစီၤတၤလမါ, ပှၤဧၤနးဖိစီၤၡံၡၤ, ဒီးစီၤအၤဃံမၣ်, ဒီးစီၤတၤလမါ, ပှၤဧၤနးဖိစီၤရှ့ၡၤ, ဒီးစီၤအၤဃံမၣ်, ဒီးစီၤတၤလမါ, ပှၤဧၤနးဖိစီၤရှ့ၡၤ, ဒီးစီၤအၤဃံမၣ်, ဒီးစီၤတၤလမါ, ပှၤဧၤနးဖိစီၤဃံ ¹⁵ ဒီးဟဲဝဲဆူပှၤဒဘ့ၤရံၤဖိလီၤ. (ဒီးလၢမုၢ်မဆါတနံၤအံၤ, ပှၤစံးဝဲဒၣ်, ဒဘ့ၤရူၤမ့ၢ်ကၤရိးၡဖၤလီၤ. ) ¹⁶ ဒီးစီၤကၤလၤစံးဝဲဒၣ်, ပှၤဟဲစိာ်ကၤရိးစဖၤ, ဒီးလဲၤစိာ်အီၤဒီး, ယကဟ့ၣ်ယဖိခွါစီၤအၤဃၤလၢအမါလီၤ. ¹⁷ ဒီးစီၤကၤနးစၤ, စီၤကၤလၤအပၢ်စီၤဧၤတၤနံၣ်လဲၤသထီၣ်ကွံာ်အီၤ, ဒီးစံးဝဲဒၣ်, စီၤပၤဟ့ၣ်အီၤအဖိခွါစီၤဧးၡၤလၢအမါလီၤ. ¹⁸ ဒီးတုၤအဟဲဝဲဒီး, စံးဝဲဒၣ်, မၤသးဘၣ်အပၢ်ဒ်သိးအကဟ့ၣ်တၢ်ကျဲပူၤလီၤ. ဒီးလဲၤလီၤကွံာ်လၢသိအလိၤ, ဒီးစီၤကၤလဘၤစံးအီၤ, နဘၣ်မနုၤလဲၣ်. ¹⁹ ဒီးစံးဝဲဒၣ်, ဟ့ၣ်ယၤလၢတၢ်အုၣ်က့ၤခီၣ်က့ၤတက့ၢ်. မ့ၢ်နဟ့ၣ်ယၤလၢကီၢ်ကိၢ်ပူၤဒီး, ဟ့ၣ်ယၤလၢထံခိၣ်လီၤ. ဒီးဟ့ၣ်အီၤထံခိၣ်အလိၤ, ဒီးထံခိၣ်အလိၤလီၤ. ²⁰ တၢ်အံၤမ့ၢ်စီၤယူဒၤဖိအကီၢ်အတၢ်မၤအသးဒ်အပၢ်တဖၣ်အသိးလီၤ. ²¹ ဒီးပှၤယူဒၤဖိအကီၢ်ပူၤလၢဧၤဒံၣ်အကီၢ်ပူၤလၢကီၢ်ကိၣ်ပူၤန့ၣ်အကီၢ်တဖၣ်မ့ၢ်ကးၡဧၤဧၤ, ဒီးဧၤဒၤ, ဒီးယဃူၤလီၤ. ²² ဒီးစီၤကၤနါ, ဒီးစီၤဒၤမၤနါ, ဒီးစီၤဧဒၤဒၤ, ²³ ဒီးစီၤကဒၤ, ဒီးစီၤဃၤစၤ, ဒီးစီၤဧၤတၤနၣ်, ²⁴ ဒီးၡး, ဒီးတၤလၣ်, ဒီးဘဧၤလၤ, ²⁵ ဒီးဃၤစၤဃဒၤတၤ, ဒီးဃၤစၤအကီၢ်တဖၣ်, ²⁶ ဒီးစီၤအၤမၣ်, ဒီးစီၤၡမါ, ဒီးစီၤမံၣ်လဒၤ, ²⁷ ဒီးကၤရးကဒါး, ဒီးကၤၡယၤ, ဒီးဘ့ၤသပၤလး, ²⁸ ဒီးစီၤဃရၤၡရှူၤ, ဒီးစီၤဘၤရၤၡဘၤ, ဒီးစီၤဘၤစယၤတၤ, ²⁹ ဒီးစီၤဘဧၤလၤ, ဒီးစီၤဧၤယၤ, ဒီးစီၤဧ့ၡၢ်, ³⁰ ဒီးစီၤဧၤလတၤ, ဒီးစီၤကၡံၣ်, ဒီးစီၤဃၣ်မါ, ³¹ ဒီးစကၤလး, ဒီးမဒၤမါ, ဒီးၡၤစၤနါ, ³² ဒီးစီၤလဘိး, ဒီးစီၤၡၤဃံ, ဒီးစီၤဧၣ်, ဒီးစီၤရၤမၣ်, စီၤပၤခံဆံခွံကီၢ်ခဲလၢာ်, ဒီးအကီၢ်ပူၤလီၤ. ³³ ဒီးလၢစၤဖလၤအပူၤ, အၤစတၤဧၤ, ဒီးစီၤစၤရၤ, ဒီးစီၤအၤစနၤ, ³⁴ ဒီးစီၤၡနါၤ, ဒီးစီၤဧၤၣ်ကၣ်ယၤ, ဒီးစီၤတၤဖူယၤ, ဒီးစီၤဧၤၣ်ယၤ, ³⁵ ဒီးစီၤယၤမူးၤ, ဒီးစီၤဧဒူလၤ, ဒီးစီၤၡကၤ, ဒီးစီၤဧ့ၡကၤ, ³⁶ ဒီးစီၤၡၤရယၤ, ဒီးစီၤဧဒၤတၤ, စီၤဃဃရၤ, ဒီးစီၤကဒြၤရၤလီၤ. စီၤပၤတဆံလွံၢ်ကီၢ်ဒီးအကီၢ်ပူၤလီၤ. ³⁷ ဒီးၡၤနၣ်, ဒီးကဒါၡၤ, ဒီးမိကဒၤကး, ³⁸ ဒီးစီၤဒၤလၣ်, ဒီးစီၤဃမၤစဖၤ, ဒီးစီၤယၤကၤဧံၣ်, ³⁹ ဒီးစီၤလၤဃၤ, ဒီးစီၤဘၤစကၤ, ဒီးစီၤဧၤဃၤလၣ်, ⁴⁰ ဒီးကးဘၣ်, ဒီးလၤဃမါ, ဒီးကံးတၤလၤ, ⁴¹ ဒီးကဒၤရၤ, ဒီးဘ့ၤသဒးကၣ်, ဒီးနဧၤမါ, ဒီးမ့ကဒၤ, ကီၢ်တဆံခံကီၢ်, ဒီးအကီၢ်ပူၤလီၤ. ⁴² ဒီးစီၤလဘၤ, ဒီးစီၤဧၤတၤ, ဒီးစီၤဧၤစၣ်, ⁴³ ဒီးစီၤယံးဖတၤ, ဒီးစီၤအၤစနၤ, ဒီးစီၤနစၤတၤ, ⁴⁴ ဒီးစီၤကၤလၤ, ဒီးစီၤဧးခိး, ဒီးစီၤမရၤဧၤ, ကီၢ်ကထိဒီးအကီၢ်ပူၤလီၤ. ⁴⁵ ဒီးဧကၤရၣ်, ဒီးအကီၢ်တဖၣ်, ဒီးအကီၢ်ပူၤတဖၣ်, ⁴⁶ ဒီးလၢဧၤကၤရၣ်ဆူပီၣ်လဲၣ်ပူၤန့ၣ်, အၤရှၤဒၤအကီၢ်ပူၤခဲလၢာ်, ဒီးအကီၢ်ဝးတရံးလီၤ. ⁴⁷ ဒီးဧၤစဒၤ, ဒီးအကီၢ်တဖၣ်, ဒီးအကီၢ်တဖၣ်, ဒီးကၤစၤ, ဒီးအကီၢ်တဖၣ်, ဒီးအကီၢ်တဖၣ်, ဒီးဆူအံၣ်စရ့လးအကစၢၢ်ကလိ, ဒီးဆူပီၣ်လဲၣ်ဒိၣ်, ဒီးလၢအကီၢ်ပူၤလီၤ. ⁴⁸ ဒီးလၢကစၢၢ်ကလိန့ၣ်စီၤၡၤမ့ၤ, ဒီးစီၤယၤတၤ, ဒီးစီၤၡၤကၤလီၤ. ⁴⁹ ဒီးဒၣ်, ဒီးကၤရယးၡၤနါ, (မ့ၢ်ဒဘံၣ်), ⁵⁰ ဒီးစီၤဧၤနး, ဒီးစီၤဧၤစတၤမါ, ဒီးစီၤဧၣ်ယၤ, ⁵¹ ဒီးကၤရှၣ်, ဒီးဃၤလၣ်, ဒီးကၤလၤ, ကီၢ်တဆံတဆံ, ဒီးအကီၢ်ပူၤလီၤ. ⁵² ဒီးစီၤဧၤရၤ, ဒီးစီၤရၤမါ, ဒီးစီၤဧ့ၡၣ်, ⁵³ ဒီးစီၤယၣ်ယၤ, ဒီးစီၤဘၤဟးၡးဖူၤ, ဒီးစီၤဧဖကၤ, ⁵⁴ ဒီးစီၤဃူမၤတၤ, ဒီးစီၤကၤရယးအၤဘၤ, (မ့ၢ်စီၤဃဘၤရၣ်), ဒီးစီၤၡၤရၤလီၤ. ကီၢ်ခွံကီၢ်, ဒီးအကီၢ်ပူၤလီၤ. ⁵⁵ ဒီးစီၤမဧၣ်, ဒီးစီၤကၤရံၣ်, ဒီးစီၤစီဖၤ, ဒီးစီၤယူးတၤ, ⁵⁶ ဒီးစီၤယံးစလၤ, ဒီးစီၤယၤကဒၤ, ဒီးစီၤၡၤနး, ⁵⁷ ဒီးစီၤဃၤဃၣ်, ဒီးစီၤဃံးဘဧၤ, ဒီးစီၤတၤမါလီၤ. ဝ့ၢ်တဆံဒီးအကီၢ်ပူၤလီၤ. ⁵⁸ ဒီးစီၤကၤလကံၣ်, ဒီးစီၤဘၤသစူၤ, ဒီးစီၤကဒံၣ်, ⁵⁹ ဒီးစီၤမၤရး, ဒီးစီၤဘၤသဧၤနး, ဒီးစီၤဧၤလတၤကၣ်, ကီၢ်ဃံကီၢ်ဃၣ်, ဒီးအကီၢ်ပူၤလီၤ. ⁶⁰ ဒီးကၤရယးဘဧၤ, (မ့ၢ်ကၤရယးဧၤရ့လး, ) ဒီးဃရၤဘၤ, ကီၢ်ခံဂၤဒီးအကီၢ်ပူၤလီၤ. ⁶¹ ဒီးလၢဟီၣ်ခိၣ်ချၢန့ၣ်ဘၤဟၤဧရၤဝၤ, ဒီးမီဒၣ်, ဒီးစကၤကၤ, ⁶² ဒီးနဘၤၡၣ်, ဒီးဆိၣ်ကီၢ်, ဒီးဧၤၣ်ကဒၤ, ကီၢ်လွံၢ်ကီၢ်ဒီးအကီၢ်ပူၤလီၤ. ⁶³ ဒီးပှၤယူဒၤဖိတဟဲစိာ်ဘၣ်ပှၤယဘၤဖိလၢအအိၣ်ဖှိၣ်ရိဖှိၣ်လၢယရူၤၡၣ်ပူၤဘၣ်. ဒီးပှၤယဘၤဖိအိၣ်ဖှိၣ်ရိဖှိၣ်ဒီးပှၤယူဒၤဖိလၢယရူၤၡၣ်ပူၤလၢမုၢ်မဆါတနံၤအံၤလီၤ.
