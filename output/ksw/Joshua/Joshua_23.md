# Joshua 23

¹ ဒီးမုၢ်နံၤအါဂၤန့ၣ်ယွၤပာ်အံၣ်စရ့လးလၢအဒုၣ်ဒွဲၣ်တဖၣ်လၢအဝးတရံးအီၤ, ဒီးစီၤယၤရှူထီၣ်ထီလၢမုၢ်တနံၤလီၤ. ² ဒီးစီၤယၤရှူၤဟဲစိာ်အံၣ်စရ့လးခဲလၢာ်, အပၢ်တဖၣ်, ဒီးအခိၣ်တဖၣ်, ဒီးအစီၤပၤတဖၣ်, ဒီးအပၢ်တဖၣ်အခိၣ်တဖၣ်, ဒီးစံးဝဲဒၣ်, ယအိၣ်ဘှံးလံ, ဒီးယမုၢ်မဆါတနံၤအံၤ, ယအိၣ်ဘှံးလံ. ³ ဒီးသုထံၣ်ဘၣ်တၢ်ခဲလၢာ်လၢယွၤသုယွၤမၤပှၤကလုာ်တဖၣ်ခဲလၢာ်လၢသုဂီၢ်လီၤ. ဘၣ်ဆၣ်ဒီးယွၤသုယွၤမ့ၢ်အလဲၤအိၣ်ဖှိၣ်ရိဖှိၣ်လၢသုဂီၢ်လီၤ. ⁴ ဒီးကွၢ်ကွၢ်, ယပာ်ပှၤကလုာ်တဖၣ်လၢသုဂီၢ်လၢသုမဲာ်ညါ, ဒ်သုဒူၣ်တဖၣ်အသိးန့ၣ်, ဒ်သိးသုကဒုးအိၣ်ဖှိၣ်ရိဖှိၣ်အီၤ, လၢယူဒၤပူၤ, ဒီးလၢပံၣ်စရ့လးပူၤလီၤ. ⁵ ဒီးယွၤသုယွၤန့ၣ်ကဒုးဟဲထီၣ်ကွံာ်အီၤလၢသုပူၤ, ဒီးကဒုးဟဲထီၣ်ကွံာ်အီၤလၢသုပူၤ, ဒီးသုကပာ်အကီၢ်လၢသုစုပူၤ, ဒ်ယွၤသုယွၤစံးဝဲဒၣ်လၢသုလီၤ. ⁶ ဒီးခဲကနံၣ်အံၤ, မၤသးဒ်န့ၣ်ဒီး, ပာ်နသးကလီကလီ, ဒ်သိးနကထိၣ်ထီၣ်, ဒီးမၤတၢ်ခဲလၢာ်လၢစီၤယၤကိာ်တၢ်အုၣ်က့ၤခီၣ်က့ၤအလံာ်ပူၤ, ဒီးသုတဃၣ်ကွံာ်လၢအပူၤဆူအစုခိၣ်, ဒီးဆူအစုစူၤရံဘၣ်. ⁷ ဒီးသုဘၣ်ဟဲဆူပှၤကလုာ်တဖၣ်လၢအအိၣ်ဖှိၣ်ရိဖှိၣ်လၢသုပူၤဘၣ်, ဒီးသုဘၣ်စံးအယွၤတဖၣ်အကလုာ်တဖၣ်, ဒီးသုဘၣ်ဆိၣ်ကွံာ်အီၤဘၣ်, ဒီးသုဘၣ်မၤအီၤဘၣ်, ဒီးသုဘၣ်ဃၣ်ကွံာ်အီၤဘၣ်. ⁸ ဘၣ်ဆၣ်ဒီးသုဘၣ်ဃၣ်ထီၣ်သုသးဆူယွၤသုယွၤ, ဒ်သုမၤလၢမုၢ်မဆါတနံၤအံၤအသိးလီၤ. ⁹ မၤသးဒ်န့ၣ်ဒီးယွၤကဒုးဟဲစိာ်ပှၤကလုာ်တဖၣ်လၢသုဂီၢ်, ပှၤအါဂၤ, ဒီးတၢ်လုၢ်အဒိၣ်တဖၣ်လီၤ. ဒီးတုၤမုၢ်မဆါတနံၤအံၤ, တမ့ၢ်ဘၣ်ပှၤအိၣ်ဖှိၣ်ရိဖှိၣ်လၢသုပူၤနီတဂၤဘၣ်. ¹⁰ ပှၤတကထိလၢသုပူၤတဂၤန့ၣ်ကဟဲစိာ်ပှၤတကထိလီၤ. ဘၣ်ဆၣ်ဒီးယွၤသုယွၤမ့ၢ်အသုးလၢသုဂီၢ်, ဒ်အစံးလၢသုလီၤ. ¹¹ ဒီးပာ်နသးလီနသးလိၤ, ဒ်သိးနကအဲၣ်ယွၤနယွၤလီၤ. ¹² ယွၤစံးဝဲဒၣ်, သုမ့ၢ်ဃၣ်ကွံာ်သုသး, ဒီးဟဲစိာ်သုသးဆူပှၤကလုာ်တဖၣ်လၢသုပူၤ, ဒီးသုမၤသးဒ်အီၤ, ဒီးအဝဲသ့ၣ်မၤသးဒ်သုအသိးန့ၣ်ဒီး, ¹³ ဒီးကွၢ်ကွၢ်, ယွၤနယွၤတဟဲစိာ်ဘၣ်ပှၤကလုာ်တဖၣ်ဆူနပူၤဘၣ်. ဒီးကကဲထီၣ်တၢ်ဆိၣ်, ဒီးကိၣ်, ဒီးသိ, ဒီးပျၢ်လၢသုမဲာ်ညါ, ဒီးကကဲထီၣ်လၢသုကလီၤဃၣ်ကွံာ်လၢကီၢ်ဂ့ၤလၢအယွၤသုယွၤဟ့ၣ်သုလီၤ. ¹⁴ ဒီးယကလဲၤလၢဟီၣ်ခိၣ်အကျဲလီၤ. ဒီးသုဘၣ်သ့ၣ်ညါလၢသုသးခဲလၢာ်, ဒီးလၢသုသးခဲလၢာ်, လၢယွၤသုယွၤစံးဝဲဒၣ်လၢသုအဂီၢ်, လၢတၢ်ဂ့ၤခဲလၢာ်န့ၣ်, တမ့ၢ်ဘၣ်အသးဘၣ်. ပှၤခဲလၢာ်ဟဲဆူနဂီၢ်လီၤ. တမ့ၢ်ဘၣ်တဂၤဘၣ်. ¹⁵ ဒီးဒ်ယွၤသုယွၤစံးဝဲဒၣ်လၢသုပူၤလၢတၢ်ဂ့ၤခဲလၢာ်န့ၣ်ဟဲလီၤလၢသုပူၤအသိးန့ၣ်ယွၤကဟဲလီၤလၢသုပူၤလၢတၢ်ဂ့ၤခဲလၢာ်န့ၣ်, ဒီးကမၤသံသုလၢဟီၣ်ခိၣ်အလိၤလၢယွၤသုယွၤဟ့ၣ်သုလီၤ. ¹⁶ ဘၣ်ဆၣ်ဒီးသုမၤတတီတလိၤဘၣ်ယွၤသုယွၤအတၢ်အၢၣ်လီၤအီလီၤလၢအမၤလိာ်သု, ဒီးလဲၤမၤယွၤအဂၤတဖၣ်, ဒီးကဆှီကွံာ်အီၤဒီး, ယွၤအသးကကဲထီၣ်လၢသုပူၤ, ဒီးသုကလီၤဃၣ်ကွံာ်ကွံာ်သုသးလၢကီၢ်ဂ့ၤလၢယွၤဟ့ၣ်သုလီၤ.
