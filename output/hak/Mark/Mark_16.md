# Mark 16

¹ 安息日一過，抹大拉个馬利亞、雅各个母親馬利亞摎撒羅米買了香料，愛去膏耶穌。 ² 七日个頭一清早，太陽剛升起个時節，佢兜來到墳墓該位。 ³ 佢兜彼此講：「麼人摎大石頭從墓門滾開哪？」 ⁴ 佢兜擎頭一看，發現石頭既經滾開了，因為石頭當大。 ⁵ 佢兜進了墳墓，看著一个少年人坐在右片，披著白袍，佢兜就當驚慌。 ⁶ 該人對佢兜講：「莫驚慌！你兜尋該分釘十字架个拿撒勒人耶穌，佢既經返生了，毋在這位。你看，佢安放个地方。」 ⁷ 「你兜去同佢講个門徒摎彼得講：『你兜愛往加利利去，該位你兜會看著佢，正如佢以前告訴過你兜个。』」 ⁸ 佢兜從墳墓出來，逃跑了，因為懼怕摎驚慌，一句話也無告訴人。 ⁹ 耶穌從死裡返生个該日朝晨，先向抹大拉个馬利亞顯現。佢曾從耶穌身上趕出七个鬼。 ¹⁰ 佢去告訴該兜正在哀哭噭个門徒。 ¹¹ 門徒聽著耶穌還活著，分佢看著了，卻毋信。 ¹² 其後，耶穌在另外兩个人往鄉下去个路上，以另一種形像顯現分佢兜。 ¹³ 佢兜轉去，把這事告訴其餘个人，佢兜也毋信。 ¹⁴ 最後，耶穌向該十一个門徒顯現，責備佢兜个毋信摎剛硬心，因為佢兜看著佢返生後，還係毋信。 ¹⁵ 又對佢兜講：「你兜愛往普天下去，向一切受造之物傳福音。 ¹⁶ 信而受洗个必得救；毋信个必分定罪。 ¹⁷ 信个人必有神蹟隨著佢兜：奉𠊎个名趕鬼，講新方言， ¹⁸ 手能醫治病人，病人一摸就痊癒了。」 ¹⁹ 主耶穌講了這兜話以後，分接著天頂，坐在上帝个右片。 ²⁰ 門徒出去傳道，主摎佢兜同工，並且用伴隨个神蹟證實佢兜个話。
