# Psalms 81

¹ （分詩班長个）按女用手鼓个調子，亞薩个詩。 ² 向𠊎兜有力个上帝歡呼，向雅各上帝歌唱！ ³ 拿起詩篇，擊打手鼓，精彩个琴聲配著豎琴！ ⁴ 月圓時吹角號，在𠊎兜節慶个日子吹號角！ ⁵ 因為這係分以色列个法令，係雅各上帝个典章。 ⁶ 佢曾在約瑟个見證中立下這約，當佢兜出埃及地時，聽著佢兜毋熟絡个語言。 ⁷ 𠊎曾除去佢兜背上个重擔，佢兜勞作个手毋再被壓迫。 ⁸ 佢兜在困境中呼求𠊎，𠊎就救佢兜；𠊎在雷暴中秘密地考驗佢兜，在米利巴个水邊試驗佢兜。細拉。 ⁹ 𠊎个百姓啊，聽𠊎講，𠊎愛向你見證，以色列，𠊎愛作證分你：你若聽從𠊎， ¹⁰ 你就毋會有外來个神，也毋好敬拜外族个神。 ¹¹ 𠊎係耶和華你个上帝，係把你從埃及地領出來个。張開口啦，𠊎愛充滿你。 ¹² 但𠊎个百姓無聽從𠊎个聲音，以色列也毋願聽從𠊎。 ¹³ 於是𠊎放任佢兜自由自在，佢兜就照自家个意念行。 ¹⁴ 若係𠊎个百姓聽從𠊎，以色列若行𠊎个道路， ¹⁵ 𠊎就使佢兜个敵人卑微，將手放在壓迫佢兜个人身上。 ¹⁶ 恨耶和華个人必向佢耗漦，佢兜个日子必永遠無望。 ¹⁷ 𠊎愛以小麥个脂油餵養佢兜，用巖中个蜜使佢兜飽足。
