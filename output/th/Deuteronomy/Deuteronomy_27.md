# Deuteronomy 27

¹ มอเสสและผู้สูงอายุของอิสราเอลได้ตรัสกับประชาชนว่า “เจ้าทุกคนจงรักษาทุกข้อบัญญัติที่ข้าพเจ้าสั่งเจ้าในวันนี้ให้ดี” ² “เมื่อวันใดที่เจ้าข้ามจอร์แดนไปยังแผ่นดินที่พระยาห์เวห์พระเจ้าของเจ้าจะมอบให้เจ้า เจ้าจะต้องตั้งหินใหญ่ไว้ และจะปิดหินเหล่านั้นด้วยดิน” ³ “เจ้าจะต้องเขียนทุกคำของธรรมบัญญัตินี้ลงบนหินเหล่านั้น เมื่อเจ้าข้ามจอร์แดนไป ซึ่งจะเกิดขึ้นเมื่อเจ้าเข้าไปในแผ่นดินที่พระยาห์เวห์พระเจ้าของบรรพบุรุษเจ้าจะมอบให้เจ้า เป็นแผ่นดินที่อุดมสมบูรณ์ด้วยน้ำนมและน้ำผึ้ง ตามที่พระยาห์เวห์พระเจ้าได้ตรัสไว้” ⁴ “เมื่อเจ้าข้ามจอร์แดนไป เจ้าจะต้องตั้งหินเหล่านี้ที่เขาเกีบัล ซึ่งข้าพเจ้าสั่งเจ้าในวันนี้ และเจ้าจะปิดหินเหล่านั้นด้วยดิน” ⁵ “เจ้าจะต้องสร้างแท่นบูชาสำหรับพระยาห์เวห์พระเจ้าของเจ้า แท่นบูชาจากหิน ห้ามใช้เหล็กขูดบนมันเลย” ⁶ “เจ้าจะต้องใช้หินที่สมบูรณ์ไม่ตัดแต่งมาสร้างแท่นบูชาสำหรับพระยาห์เวห์พระเจ้าของเจ้า และจะนำเครื่องบูชาไฟเผาอันศักดิ์สิทธิ์ขึ้นมาบนแท่นนั้นเพื่อพระยาห์เวห์พระเจ้าของเจ้า” ⁷ “เจ้าจะต้องสังเวยเครื่องบูชาสันติสุขและกินที่นั่น และจะได้รับความสุขสมใจที่อยู่หน้าพระยาห์เวห์พระเจ้าของเจ้า” ⁸ “เจ้าจะต้องเขียนข้อธรรมบัญญัตินี้ลงไปบนหินทุกอย่างอย่างชัดเจนและละเอียด” ⁹ มอเสสและปุโรหิตเลวีได้ตรัสกับทั้งอิสราเอลว่า “ให้เงียบเถิด และฟังเถิด โอ้อิสราเอล ในวันนี้เจ้าได้กลายเป็นประชาคมของพระยาห์เวห์พระเจ้าของเจ้า” ¹⁰ “เจ้าจงฟังเสียงพระยาห์เวห์พระเจ้าของเจ้า และปฏิบัติตามทุกข้อบัญญัติและประเพณีของพระองค์ ตามที่ข้าพเจ้าสั่งเจ้าในวันนี้” ¹¹ มอเสสได้ตรัสกับประชาชนในวันนั้นว่า ¹² “เหล่านี้จะยืนอยู่เพื่อให้พรแก่ประชาคมเมื่อเจ้าข้ามจอร์แดนไป ได้แก่ ซีเมียน เลวี ยูดาห์ อิสอัค โยเซฟ และเบนยามิน” ¹³ “เหล่านี้จะยืนอยู่เพื่อสาปแช่งบนเขาเกีบัล ได้แก่ รูเบน กัด อัสเซอร์ ซับบูลุน ดาเนียล และเนฟทาลี” ¹⁴ “เลวีจะตอบกลับด้วยเสียงอันดังทั้งหมดแก่ประชาคมอิสราเอลว่า” ¹⁵ “อัตถิริย์แก่ชายผู้ทำรูปเคารพหรือรูปสลัก ซึ่งเป็นสิ่งที่พระยาห์เวห์ทรงเกลียดชัง และเป็นงานฝีมือของนักแกะสลัก แล้วนำไปซ่อนไว้ ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ¹⁶ “อัตถิริย์แก่ผู้ดูถูกพ่อหรือแม่ของตน ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ¹⁷ “อัตถิริย์แก่ผู้เปลี่ยนเขตแดนของเพื่อนบ้าน ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ¹⁸ “อัตถิริย์แก่ผู้นำทางคนตาบอดให้หลงทาง ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ¹⁹ “อัตถิริย์แก่ผู้บิดเบือนความยุติธรรมของผู้แปลกหน้า ทารกกำพร้า หรือผู้หญิงไร้สามี ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ²⁰ “อัตถิริย์แก่ผู้นอนอยู่กับภรรยาของพ่อของตน เพราะเขายังไม่ได้เปิดเผยเส้นทางของพ่อของตน ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ²¹ “อัตถิริย์แก่ผู้นอนอยู่กับสัตว์ ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ²² “อัตถิริย์แก่ผู้นอนอยู่กับพี่สาวของพ่อหรือแม่ของตน ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!”

²³ “อัตถิริย์แก่ผู้นอนอยู่กับสะใภ้ของตน ประชาคมท  
ั้งหมดจะตอบว่า ถูกต้อง!”  

²⁴ “อัตถิริย์แก่ผู้ตีเพื่อนบ้านของตนอย่างลับๆ ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ²⁵ “อัตถิริย์แก่ผู้รับสินบนเพื่อฆ่าชีวิตคนบริสุทธิ์ ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!” ²⁶ “อัตถิริย์แก่ผู้ไม่ยึดมั่นปฏิบัติตามทุกข้อของธรรมบัญญัตินี้ ประชาคมทั้งหมดจะตอบว่า ถูกต้อง!”

Notes
- v. 14: ใช้คำว่า “เลวี” ตามที่ระบุในตารางชื่อ แม้ในบางบริบทอาจหมายถึงกลุ่มคนทั่วไป
- v. 15: คำว่า "תּוֹעֲבַת" (to'evah) แปลว่า "สิ่งที่พระองค์ทรงเกลียดชัง" ตามความหมายในบริบททางศาสนา
- v. 17: คำว่า "גְּבוּל" แปลว่า "เขตแดน" ไม่ใช่ "เส้นแบ่ง" ตามที่บางภาษาอาจแปล
- v. 23: เนื้อความในภาษาฮีบรูไม่ชัดเจนว่าหมายถึง "สะใภ้" หรือ "ภรรยาของพี่สาว" แต่ใช้คำว่า "สะใภ้" ตามการแปลมาตรฐานของคำว่า "חֹתַנְתּוֹ" (chotnano)
