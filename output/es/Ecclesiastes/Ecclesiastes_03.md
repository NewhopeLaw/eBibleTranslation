# Ecclesiastes 3

¹ Hay un tiempo para cada cosa, y una época para cada deseo bajo el sol: ² un tiempo para nacer, y un tiempo para morir; un tiempo para plantar, y un tiempo para arrancar lo plantado; ³ un tiempo para matar, y un tiempo para sanar; un tiempo para destruir, y un tiempo para construir; ⁴ un tiempo para llorar, y un tiempo para reír; un timepo para lamentarse, y un tiempo para bailar; ⁵ un tiempo para lanzar piedras, y un tiempo para recoger piedras; un tiempo para abrazar, y un tiempo para apartarse del abrazo; ⁶ un tiempo para buscar, y un tiempo para perder; un tiempo para guardar, y un tiempo para desechar; ⁷ un tiempo para rasgar, y un tiempo para tejer; un tiempo para guardar silencio, y un tiempo para hablar; ⁸ un tiempo para amar, y un tiempo para odiar; un tiempo para la guerra, y un tiempo para la paz. ⁹ ¿Qué ventaja tiene el que hace lo que ya ha sido hecho? ¹⁰ Ya vi el asunto que Dios dio a los hijos de la humanidad, para que en ello se ocuparan. ¹¹ Todo lo hizo hermoso en su tiempo, y también puso en sus corazones el mundo futuro, sin que el hombre alcance a comprender la obra que Dios ha hecho desde el principio hasta el final. ¹² He sabido que no hay nada mejor para ellos que alegrarse y hacer el bien en su vida. ¹³ Y también que todo hombre que coma y beba y vea el bien en todo su trabajo, es una dádiva de Dios. ¹⁴ He sabido que todo lo que Dios hace durará para siempre, no se le puede añadir ni restar nada, y Dios lo hizo para que le teman delante de él. ¹⁵ Lo que fue, ya fue, y lo que será, ya fue. Y Dios buscará lo que huyó. ¹⁶ Y vi también bajo el sol que hay lugar para el juicio, y allí el malo; y lugar para la justicia, y allí el malvado. ¹⁷ Dije para mí: «El justo y el malo los juzgará Dios, porque hay un tiempo para cada deseo, y para cada obra». ¹⁸ Dije para mí: «En cuanto a la cuestión de los hijos de la humanidad, Dios los prueba para que vean que son como las bestias». ¹⁹ Porque el destino de los hijos de la humanidad y el destino de las bestias es uno solo: hay un mismo destino para todos. Como muere uno, así muere otro; y hay un mismo espíritu para todos. Y no hay ventaja para el hombre sobre la bestia, porque todo es vanidad. ²⁰ Todo va a un mismo lugar: todo provino del polvo, y todo vuelve al polvo. ²¹ ¿Quién conoce si el espíritu de los hijos de la humanidad sube arriba, y si el espíritu de la bestia baja abajo a la tierra? ²² Y vi que no hay ventaja mejor para el hombre que alegrarse en sus obras, porque ése es su recompensa, porque nadie le hará saber con quién se le mostrará lo que será después de él.

---

Notes  
- v. 4: "sobre" en "un tiempo para lamentarse, y un tiempo para bailar" se usa como preposición equivalente a "de", no como adverbio.  
- v. 11: "mundo futuro" traduce el término "eternity" (olam), aquí en un contexto de visión o intuición sobre lo que está por venir, no como un lugar.  
- v. 15: "buscará lo que huyó" refleja el juego de ideas entre lo que ha sido, lo que será y la noción de que Dios persigue lo que huye (el tiempo o los momentos perdidos).  
- v. 17: "el justo y el malo los juzgará Dios" refleja la idea de que, aunque bajo el sol se ve injusticia, Dios juzgará en su tiempo.  
- v. 21: "espíritu" (nephesh) se ha traducido como "espíritu" en este contexto filosófico, aunque podría ser "aliento" u "uno mismo", según norma general, pero aquí se mantiene "espíritu" por coherencia narrativa.
