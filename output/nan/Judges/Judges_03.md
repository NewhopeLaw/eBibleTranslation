# Judges 3

¹ 耶和華留遮些民族，讓𪜶成做試驗以色列人的對象，就是遐的以色列人未曾佮𪜶爭戰、未曾捌的迦南一切戰爭。 ² 這是為了欲試驗以色列人的後代，使𪜶學習戰爭，遐的佇𪜶之前的人未曾學過。 ³ 五个亞瑪力人的首領，猶有迦南人、西頓人、赫人，住佇黎巴嫩山，從伯亞蘭的黑門山直到哈馬口。 ⁴ 𪜶留在遐，是為了欲試驗以色列人，看𪜶是否肯聽從耶和華的誡命，就是耶和華藉著摩西向𪜶列祖所吩咐的。 ⁵ 以色列人住佇迦南人、希未人、亞摩利人、比利洗人、希未人佮耶布斯人中間。 ⁶ 𪜶娶了遐的人的查某囝作妻子，閣把𪜶的查某囝嫁給遐的人的後生；𪜶事奉遐的人的神。 ⁷ 以色列人行耶和華眼中看為惡的事，袂記得了耶和華𪜶的上帝，去事奉諸巴力佮亞斯伊錄。 ⁸ 耶和華向以色列人發怒，就把𪜶交佇基比亞人亞蘭王古珊利薩田的手中，以色列人服事古珊利薩田八年。 ⁹ 以色列人呼求耶和華，耶和華就為以色列人興起一位拯救者，就是基列人希百的後生耶弗伊，伊是以笏的妹子亞比該的後生。 ¹⁰ 耶和華的靈降佇伊身上，伊就作了以色列的審判官，下到亞捫人遐去佮𪜶爭戰。 ¹¹ 耶和華將亞捫人交佇伊手裡，伊就打敗了𪜶，從亞羅珥直到米斯巴，以及米斯巴的四境；以色列人就會得通安息四十年。 ¹² 以色列人閣行耶和華眼中看為惡的事，耶和華就把摩押王伊磯倫交佇𪜶手中。 ¹³ 以色列人服事伊磯倫十八年， ¹⁴ 以色列人呼求耶和華，耶和華就興起一位拯救者，就是便雅憫人基比亞人以笏，伊是倒手的人。 ¹⁵ 以色列人打發伊帶著禮物去見摩押王伊磯倫。 ¹⁶ 以笏為家己作了一把雙刃的劍，長一肘，綁佇腿上，穿佇正爿。 ¹⁷ 伊把禮物獻給摩押王伊磯倫，伊磯倫是个真強壯的人。 ¹⁸ 伊獻完禮物，就打發遐的抬禮物的人轉去。 ¹⁹ 伊回到近倚吉甲的刀匠遐，對王講：「你有密事求見王。」王講：「隱藏吧。」於是王的侍衛攏離開伊。 ²⁰ 以笏走近伊，伊正單獨坐在涼棚裡。以笏講：「我有神的事欲共你講。」王就從坐位上起來。 ²¹ 以笏倒手一伸，從右腿上抽出劍來，刺入王的肚腹， ²² 刺入王的肚腹後，刀柄嘛跟著入去，脂肪卡住了刀，伊無把刀從王的肚腹裡拔出來。 ²³ 以笏行出去，把棚門關上，然後鎖上。 ²⁴ 伊剛出去，僕人就入來了，看著棚門鎖著，就講：「伊一定是佇涼棚裡大小便。」 ²⁵ 𪜶等了一會兒，見王毋開棚門，就拿鎖匙開了門，恁看，𪜶的主僕已經倒佇地上死了。 ²⁶ 以笏逃走，直到𪜶平靜下來；伊經過刀匠遐，逃到西珥亞拉。 ²⁷ 伊吹角佇以法蓮山地，以色列人就隨著伊落來，伊行佇𪜶頭前。 ²⁸ 伊對𪜶講：「跟我來吧！因為耶和華已經把恁的仇敵摩押人交佇恁手中。」𪜶就跟著伊落去，把約旦河渡口攔住，不讓一人過去。 ²⁹ 當日，𪜶擊殺摩押人，擊殺了一萬人，攏是精銳的勇士，無一人脫離。 ³⁰ 那日，摩押佇以色列人手下敗北，以色列地就太平了八十年。 ³¹ 以笏了後，有亞拿的後生珊迦興起，伊用趕牛的棍仔殺了六百个非利士人，伊嘛救了以色列。
