# Jeremiah 3

¹ 耶和華講：「人若休了妻子，伊離開伊以後去嫁別人，彼查某人猶閣會當回到前翁遐無？伊轉去的話，彼地嘛必予玷汙，伊佮伊的翁婿攏必行淫。恁嘛像按呢離棄我，綴許多外邦的神明，竟還講欲回到我遮。」 ² 舉目向曠野觀看，看看你佇何處躺臥，你是佇各條路上歇睏，像曠野的野狗仝款躺臥。你玷汙了彼地，用家己的淫行佮惡質。 ³ 你為家己聘了許多牧人，𪜶卻成了你的絆腳石。你成了妓女的模樣，使家己佇眾人面前見笑。 ⁴ 你敢曾稱呼我為父親，為引導你年幼時的夫子無？ ⁵ 你敢掠準家己能永遠毋予發現，能永遠毋予懲罰？恁看，你講了這話，嘛做了這事，卻猶原得逞。 ⁶ 耶和華對我講：「你看著以色列家所行的事了無？𪜶往各懸山去，往各樣樹木落去，去遐行淫。」 ⁷ 我講：「伊既然按呢行了，我閣向伊施恩，伊卻毋踅輾轉。後來伊看著小妹猶大嘛行了淫亂。」 ⁸ 我看著以色列家犯了姦淫，我就把休書交給伊，送伊出去。伊卻無因家己的小妹猶大而感到見笑，反倒轉嘛去行淫亂。 ⁹ 𪜶行淫的結果使地荒涼，連石頭佮樹木嘛做伙予玷汙。 ¹⁰ 就是佇遮的事上，猶大嘛無踅輾轉到我遮，而是用謊言獻上心。 ¹¹ 耶和華對我講：「以色列的罪比猶大的罪更小。」 ¹² 「你欲下落北方講這話，講：『以色列的餘民哪，欲回轉到我遮來。』這是耶和華講的。我袂向恁發怒，因為我是有恩典的，袂永遠責備恁。」 ¹³ 「毋過你欲知影你的罪，你悖逆了耶和華你的上帝，偏離了伊的道路，往各樣的樹木落去，毋聽從伊的聲音。」這是耶和華講的。 ¹⁴ 「踅輾轉啦，背道的兒女。」這是耶和華講的。「我必作恁的主，從一城中領一人，從一家中領兩个人，將恁帶回錫安。」 ¹⁵ 「我還要予恁忠心的牧人，𪜶欲以智慧佮知識牧養恁。」 ¹⁶ 「將來恁佇彼地上人數增多，繁榮起來的時，」這是耶和華講的，「恁再也不會講『約櫃是耶和華的』，恁袂閣記起伊，袂閣去揣伊，嘛袂閣製造伊。」 ¹⁷ 「彼時，耶路撒冷必被稱作耶和華的寶座，列國攏必到遐尋求上帝的名，無閣隨從家己惡質的心意。」 ¹⁸ 「彼時，猶大家佮以色列家必做伙從北方來，到我所賜給恁公媽的土地。」 ¹⁹ 「我本會使將恁種作成列國，賜給恁上帝所揀選的美地，還講『恁欲稱我為父，無閣離棄我』。」 ²⁰ 「但恁竟像背棄翁婿的婦人仝款背棄了我。」這是耶和華講的。 ²¹ 「從嘴唇發出的聲音，是哀哭佮懇求的聲音；以色列的兒女因家己惡質的行徑，袂記得了聖潔的上帝。」 ²² 「踅輾轉啦，背道的人，我必醫治恁。」恁看，阮是你的僕人，你才是阮的上帝。 ²³ 「確實，山嶺佮高岡是虛假的，救恩卻只佇耶和華阮的上帝遐。」 ²⁴ 「羞辱已經吞滅了阮公媽的勞苦，從阮年幼時起，𪜶的羊群、牛群、兒女攏失去了。」 ²⁵ 「阮因羞辱而落眠，因羞辱而蒙蓋。因為阮從年幼直到今仔日，一直佇上帝面前犯罪，無聽從耶和華阮上帝的聲音。」
