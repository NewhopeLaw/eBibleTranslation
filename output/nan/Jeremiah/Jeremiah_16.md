# Jeremiah 16

¹ 耶和華對我講： ² 「你毋通娶妻，嘛毋通佇本地生兒養女。 ³ 因為耶和華論及這地所生的兒女，以及𪜶的母親所養的兒女，猶有𪜶的父親所生的兒女，講： ⁴ 𪜶必死於瘟疫，袂得埋葬，袂得哀哭；像廢土堆佇地面，予刀劍、飢荒所滅，成做天頂的飛鳥佮地上的野獸的食物。」 ⁵ 「因此，耶和華講：你毋通進喪家，毋通去弔喪，嘛毋通為𪜶哀哭；因為我已從這百姓中收回平安佮慈愛。」 ⁶ 「𪜶的老少攏必死佇這地上，袂得埋葬，袂得哀哭，嘛袂得剃頭或剪髮。 ⁷ 毋通佇𪜶中間設宴席，嘛毋通佇𪜶中間飲酒，為𪜶喪事的哀哭佮安慰。 ⁸ 你毋通進酒席，佮𪜶做伙坐席食啉。」 ⁹ 因為耶和華萬軍之上帝講：我必從這所在，佇恁眼前，佇恁的日子中，除滅喜樂的聲、歡樂的聲、新郎的聲、新娘的聲。 ¹⁰ 「當你對這百姓宣告這一切話時，𪜶必問你講：『這一切災禍為何臨到阮？阮的罪惡佮過犯佇佗位咧？阮為何得罪了耶和華阮的上帝？』 ¹¹ 你必回答𪜶：『恁的公媽離棄了我，去事奉別神，敬拜𪜶；𪜶離棄了我，嘛毋守我的律法。』 ¹² 恁比恁的公媽更壞，恁各人隨從家己心內的惡念，毋肯聽從我。」 ¹³ 「我必把恁從這地上趕出去，到恁佮恁的公媽攏毋捌的所在，恁佇遐必事奉別神，暝日不斷；我無閣施恩予恁。」 ¹⁴ 「因此，恁看！日子將到，耶和華講，人無閣講『耶和華拯救以色列人脫離埃及地』； ¹⁵ 而是講『耶和華拯救以色列人脫離北方之地，脫離所有我驅逐𪜶去的所在』，並將𪜶帶回我賜給𪜶公媽之地。」 ¹⁶ 「恁看！我必差遣許多討海人，耶和華講，𪜶必漁捕𪜶；了後我必差遣許多獵人，𪜶必從每座山、每座山嶺、每處巖穴中獵捕𪜶。」 ¹⁷ 因為我的目睭看顧𪜶一切的道路，𪜶的罪惡佇我毋捌隱藏。 ¹⁸ 「我欲以加倍的懲罰回報𪜶的罪惡佮過犯，𪜶因家己的穢涗佮惡質玷汙了我的地，使我的產業荒廢。」 ¹⁹ 耶和華是我的力量、我的倚靠、我的避難所；佇困苦的日子中，列國必從地極來到你遐，講： ²⁰ 「阮的公媽所雕刻的神像，只是虛假的，毫無用處。」 ²¹ 「人若為家己造神像，遐的神像嘛毋過是假神。」
