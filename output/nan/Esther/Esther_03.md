# Esther 3

¹ 遮的事以後，亞哈隨魯王抬舉了亞甲族哈默大人的後生哈曼，使伊高過一切臣僕，讓伊坐佇宮門之上。 ² 王的宮門前所有臣僕攏跪拜並叩拜哈曼，因為王按呢吩咐𪜶；末底改卻毋跪嘛毋叩拜。 ³ 王的宮門前的臣僕就對末底改講：「你為何違背王的命令咧？」 ⁴ 𪜶逐工按呢對伊講，伊卻毋聽，𪜶就把這事共哈曼講，欲看末底改的言語是否真的；因為有人共𪜶講，末底改是猶大人。 ⁵ 哈曼看著末底改毋跪嘛毋叩拜家己，就甚發怒。 ⁶ 伊看這事不足以對末底改一人下手，因為有人共伊講末底改的族人，於是哈曼就設謀欲除滅亞哈隨魯王全國境內所有猶大人，就是末底改的族人。 ⁷ 亞達月十三日，就是正月，是亞哈隨魯王紀年的時，哈曼將籤（就是普珥）拋佇面前，為欲擇定日期。普珥就是籤，拋了十二个月，就是亞達月。 ⁸ 哈曼對亞哈隨魯王講：「國中有一个百姓，四散佇王各省的百姓中，𪜶的律例佮別國的律例不同，嘛毋守王的律例；所以留著𪜶對王不利。」 ⁹ 王若掠準美，就請降旨，將𪜶滅絕，我必用一萬伊連得銀子交給當權的人，好將𪜶做店面王的稅款投入王的府庫。 ¹⁰ 王就從家己的手上摘下手指，賜給哈曼，亞甲族哈默大人哈曼的後生，猶大人的仇敵。 ¹¹ 王對哈曼講：「銀子會使歸你，彼百姓嘛任你作事。」 ¹² 於是王的書記佇正月十三日予召來，照著哈曼所吩咐的，寫信，寄往王各省，用王的權柄，用王的名，寫信給各省總管佮各省的首領，以及各族的首領，按各省的文字，用各族的語言，寫信給亞哈隨魯王。 ¹³ 信上用王的手指頓印，交由驛卒送往各省，欲滅絕、殺戮、除滅亞哈隨魯王全國境內所有的猶大人，從少至老，連查某人囡仔攏做伙毀滅；𪜶的財寶嘛做店面掠物。 ¹⁴ 這封信的抄本欲佇各城發佈，通知百姓，使𪜶預備那日。 ¹⁵ 驛卒奉王命急速起行，法令佇書珊城頒佈；王佮哈曼坐下飲酒，書珊城卻驚惶不已。
