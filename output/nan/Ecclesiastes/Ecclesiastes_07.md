# Ecclesiastes 7

¹ 好名聲勝過好膏油，死人的日子勝過活人出世的日子。 ² 去參加喪禮比參加筵席更佳，因為這結局是所有人的命運；活人應當以此為戒。 ³ 發怒勝過歡笑，因為人面帶愁容時，心內卻感到安慰。 ⁴ 智慧人的內心佇喪禮中，愚昧人的心卻佇歡樂中。 ⁵ 聽智慧人責備的話，勝過聽愚昧人唱的歌。 ⁶ 像鍋下燒火的噪音仝款，愚人的歡笑嘛是虛空。 ⁷ 暴怒的壓迫會使人跋倒，嘛會使禮物的價值予抹去。 ⁸ 代誌的結局比起頭好，心平氣和勝過驕傲自大。 ⁹ 毋通讓你的心輕易動怒，因為憤怒只會佇愚人懷裡暫時安息。 ¹⁰ 毋通講：「向時的日子比這馬的好」，你按呢問並毋是出於智慧。 ¹¹ 智慧勝過產業，洞察力勝過看著日頭的人。 ¹² 因為智慧的蔭庇勝過金錢的蔭庇，知識的優點介在智慧能使持伊的人活命。 ¹³ 請看上帝所做的事，啥人能糾正伊所做的錯事呢？ ¹⁴ 佇好日裡欲喜樂，佇壞日子裡嘛欲看，因為上帝按呢安排，是欲讓人揣無夠比這更大的事。 ¹⁵ 我佇虛妄的日子中見過一切；有義人因家己的義而滅亡，嘛有惡人長久行惡。 ¹⁶ 毋通過於老實，嘛毋通過於聰明，若無你為啥物滅亡呢？ ¹⁷ 毋通多行歹代，嘛毋通傷過愚昧，若無你為啥物無端死亡呢？ ¹⁸ 把握住這一个，嘛毋通放鬆彼一个，因為敬畏上帝的人會使從這一切中出來。 ¹⁹ 智慧能保護智慧人勝過十个統轄城中的王。 ²⁰ 因為世上無一个完全老實的人能做功德而毋犯罪。 ²¹ 對於別人所講的話，毋通全盤接受，若無你可能就像毋聽家己僕人咒罵你的人仝款。 ²² 因為你嘛曾經咒罵別人，你的心嘛多次按呢經歷過。 ²³ 我用智慧嘗試過這一切，講我欲聰明，卻發現智慧離我甚遠。 ²⁴ 遐的已經發生的代誌，遙遠而深奧，深奧得無人能揣著。 ²⁵ 我的心反覆思想，追求智慧佮推理，以明白惡質、愚昧佮瘋狂的根源。 ²⁶ 我發現比死亡還苦的是查某人，伊是个陷阱，伊的心是牢籠，伊的手是羅網。對上帝而言，伊若做功德，就能脫離；若犯罪，就會予伊困住。 ²⁷ 恁看，這是我揣著的，我以智慧尋求，欲揣著推理。 ²⁸ 我的心曾尋求，卻無揣著一个完全老實的人，只揣著一千人中的一人；至於查某人，我嘛揣無夠。 ²⁹ 恁看，這是我揣著的，就是上帝創造人是老實的，但人卻追求了無數的詭計。
