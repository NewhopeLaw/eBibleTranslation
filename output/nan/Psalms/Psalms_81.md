# Psalms 81

¹ （予詩班長的）按女用手鼓的調子，亞薩的詩。 ² 向阮有力的上帝歡呼，向雅各上帝歌唱！ ³ 拿起詩篇，擊打手鼓，美妙的琴聲配著豎琴！ ⁴ 月圓時吹角號，佇阮節慶的日子吹號角！ ⁵ 因為這是予以色列的法令，是雅各上帝的典章。 ⁶ 伊曾佇約瑟的見證中立下這約，當𪜶出埃及地時，聽著𪜶毋熟悉的語言。 ⁷ 我曾除去𪜶背上的重擔，𪜶勞作的手無閣被壓迫。 ⁸ 𪜶佇困境中呼求我，我就救𪜶；我佇雷暴中秘密地考驗𪜶，佇米利巴的水邊試驗𪜶。細拉。 ⁹ 我的百姓啊，聽我講，我欲向你見證，以色列，我欲作證予你：你若聽從我， ¹⁰ 你就袂有外來的神，嘛毋通敬拜異族的神。 ¹¹ 我是耶和華你的上帝，是把你從埃及地領出來的。張開口啦，我欲充滿你。 ¹² 但我的百姓無聽從我的聲音，以色列嘛毋願聽從我。 ¹³ 於是我放任𪜶隨心所欲，𪜶就照家己的意念行。 ¹⁴ 若是我的百姓聽從我，以色列若行我的道路， ¹⁵ 我就使𪜶的敵人微弱，將手放在壓迫𪜶的人身上。 ¹⁶ 恨耶和華的人必向伊講白賊，𪜶的日子必永遠無望。 ¹⁷ 我欲以小麥的脂油餵養𪜶，用巖中的蜜使𪜶飽足。
