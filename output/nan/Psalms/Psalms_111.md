# Psalms 111

¹ 我欲全心稱謝耶和華，佇老實人佮會眾中傳揚伊的作為。 ² 耶和華的作為偉大，伊所喜悅的事，攏是可追尋的。 ³ 伊的作為滿有榮耀佮威嚴，伊的公義永遠長存。 ⁴ 伊記念家己的奇事，伊是慈悲、有憐憫的主。 ⁵ 伊賜食物予敬畏伊的人，伊永遠記念家己的約。 ⁶ 伊向家己的百姓顯明伊作為的力量，好將列國的產業賜給𪜶。 ⁷ 伊手所作的工有真實佮公義，伊一切的命令攏是可靠的。 ⁸ 攏是永遠立定、堅定不變的，是按真實佮老實設立的。 ⁹ 伊向百姓發出救恩的命令，永遠立定了家己的約；伊的名是聖的，可畏的。 ¹⁰ 敬畏耶和華是智慧的開端；凡行伊命令的人，攏有優美的悟性；伊的讚美永遠長存。
