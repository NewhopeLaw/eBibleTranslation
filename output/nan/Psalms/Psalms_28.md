# Psalms 28

¹ 耶和華啊，我向你呼求，我的盤石，求你毋通靜默無聲。若你靜默無聲，我就佮下坑的人仝款，佮下到坑裡的人做伙滅亡。 ² 求你垂聽我懇求的聲音，我向你呼求的時，願我攑手呼求進入你聖殿的院中。 ³ 求你毋通把我共做歹的人做伙牽引，嘛毋通把我共行無義的人做伙除滅。遐的口裡講和平，心內卻懷著詭詐的人，毋通佮𪜶同歸於盡。 ⁴ 願你照著𪜶所行的報應𪜶，照著𪜶手所作的惡質，照著𪜶手所做的，予𪜶應得的報償，使𪜶承受家己行為的後果。 ⁵ 因為𪜶毋明白耶和華的作為，嘛毋明白伊手所做的工，你必拆毀𪜶，不讓𪜶閣建立。 ⁶ 耶和華啊，你應當受頌讚，因為你垂聽了我懇求的聲音。 ⁷ 耶和華是我的力量，是我的盾牌；我的心倚靠伊，我就蒙了保護。我心歡喜，我欲向伊歌頌呵咾。 ⁸ 耶和華是伊百姓的力量，是伊救恩的保障，是伊受膏者的盾牌。 ⁹ 求你拯救你的百姓，祝福你的產業，牧養𪜶，直到永遠。
