# Galatians 5

¹ 基督釋放了阮得自由，所以恁欲站穩，毋通閣予奴役的軛轄制矣。 ² 我保羅共恁講，恁若受割禮，基督就對恁無益了。 ³ 我閣指著所有人作見證，受了割禮的人，就有責任遵守全律法。 ⁴ 恁遐的依靠律法而自掠準義的人，已經佮基督隔絕，脫離了恩典矣。 ⁵ 阮靠著聖靈，憑信心仰望佇義上的盼望。 ⁶ 基督耶穌裡，受割禮毋受割禮攏無要無緊，要緊的是信心藉著愛運行。 ⁷ 恁原是走得好，是啥人攔阻了恁，毋叫恁順從真理咧？ ⁸ 這勸誘恁的，毋是從彼召恁的發出的。 ⁹ 一點面酵能使全團發起來。 ¹⁰ 我佇主裡深信恁必毋懷別樣的心；但攪擾恁的，無論是啥人，必擔當伊的罪。 ¹¹ 但我，弟兄，若還傳割禮，為啥物還受逼迫咧？彼十字架的絆腳石就荒廢了。 ¹² 願彼攪吵恁的人，連肉帶骨攏受割除矣。 ¹³ 弟兄，恁蒙召是為了自由，只是毋通將自由做店面放縱的藉口，而欲用愛互相服事。 ¹⁴ 規个律法攏包含佇一條誡命裡：「你欲愛人如己。」 ¹⁵ 恁若彼此咬咬，互相吞食，當小心，恐驚彼此予吞滅。 ¹⁶ 我講，恁欲予聖靈引導，就毋通去成就肉體的慾望。 ¹⁷ 因為肉體的慾望佮聖靈的慾望對反，聖靈佮肉體嘛彼此為敵，使恁袂當行所願意的。 ¹⁸ 恁若予聖靈引導，就毋佇律法之下。 ¹⁹ 屬肉體的行為是明顯的，就是淫亂、穢涗、邪蕩， ²⁰ 拜偶像、行邪術、冤仇、爭競、忌恨、惱怒、結黨、紛爭、異端， ²¹ 赤目、醉酒、宴樂，以及類似的事，我先前講過，這馬閣講：行遮的事的人，必袂當承受上帝的國。 ²² 聖靈的果子是愛、喜樂、和平、忍耐、恩慈、良善、信實， ²³ 溫柔、節制；按呢的事無律法禁止。 ²⁴ 凡屬基督耶穌的人，是已經把肉體佮肉體的慾望、私慾攏釘佇十字架上了。 ²⁵ 阮若靠聖靈得生，就當靠聖靈行事。 ²⁶ 毋通貪圖虛榮，彼此惹氣，互相赤目。
